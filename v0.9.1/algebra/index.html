Pauli, Ladder & Tensor Algebra

The low-level string algebra the whole engine is built on. Three tableau encodings of an N-spin operator share one dict-based machinery: the Pauli representation, whose product stays a single string and keeps the Liouvillian sparse; the ladder representation, which resolves definite coherence-order (weight) sectors at the cost of products that fan out into sums; and the spherical-tensor representation for spin > 1/2 sites, whose product likewise fans out into a sum of tensors.

Pauli Strings

A Pauli string is a symplectic (x, z) bit-tableau, two 64-bit words, so N <= 64 in this dense form (the sparse twin at the end of this page lifts that cap). Its defining property is that the product of two strings is a single string times a phase in {+-1, +-i}, so every Liouvillian matrix element is one string multiply and 𝓛 stays sparse. Two derived quantities tag the sectors the basis is built from: the grade (number of non-identity sites, the correlation order truncated on) and the order_parity (parity of the coherence order, conserved by any S_z-preserving dynamics).

RestrictedSpinDynamics.PauliLabel — Type
PauliLabel = NTuple{2, UInt64}

A single Pauli string on up to 64 spins as a symplectic (x, z) bit-tableau: bit k-1 of x marks an X-part on site k, bit k-1 of z a Z-part (per site I=(0,0), X=(1,0), Y=(1,1), Z=(0,1)). isbits, hashable and ordered, so it makes a fast dict key. The product of two labels is a single label times a phase in {+-1, +-i} (pauli_mult), which keeps 𝓛 sparse.

RestrictedSpinDynamics.PAULI_ID — Constant
PAULI_ID

The identity Pauli string I ⊗ ... ⊗ I, i.e. (UInt64(0), UInt64(0)) (empty support and grade 0). The unit of pauli_mult.

source
RestrictedSpinDynamics.grade — Function
grade(p::PauliLabel, N) -> Int

Grade = number of non-identity sites (correlation order) = popcount(x | z). The quantity the basis is truncated by.

Examples

julia> grade(PAULI_ID, 4)   # identity acts on no sites
0
source
RestrictedSpinDynamics.order_parity — Function
order_parity(p::PauliLabel) -> 0 or 1

Parity of the coherence order (U(1) charge under z-rotation) of p: popcount(x) mod 2, so 0 = even, 1 = odd. A Cartesian string of transverse support k = popcount(x) spans coherence orders {-k,...,+k} in steps of 2, so its order is not definite but its parity is, and any Sz-preserving dynamics conserves it, the sector tag behind the parity=:even|:odd option of [`restrictedbasis](@ref). The signed coherence order needs the ladder basis ([lweight`](@ref)).

Examples

julia> order_parity(PAULI_ID)              # identity: even
0

julia> order_parity((UInt64(1), UInt64(0)))   # single X: odd (single-quantum)
1
source
RestrictedSpinDynamics.pauli_mult — Function
pauli_mult(p, q, N) -> (r, phase)

Product Pp · Pq = phase · P_r, phase ∈ {±1, ±i}. Word-parallel: r = (x1⊻x2, z1⊻z2), phase = i^e with e = |x1∧z1|+|x2∧z2|−|x3∧z3|+2|z1∧x2| (popcounts). N unused (kept for API).

Examples

julia> r, phase = pauli_mult((UInt64(1), UInt64(0)), (UInt64(1), UInt64(1)), 1);  # X·Y = iZ

julia> grade(r, 1)      # a single Z
1

julia> phase == im
true
source
pauli_mult(a::SparsePauliLabel, b::SparsePauliLabel, N) -> (r, phase)

Sparse twin of the tableau product: merge the two ascending site lists, XOR the (x,z) bits at coincident sites, accumulate the symplectic phase per site, drop sites that cancel to identity. One string x phase, bit-for-bit equal to the PauliLabel product (the phase exponent is a per-site sum, reassociated here).

source
RestrictedSpinDynamics.pauli_comm — Function
pauli_comm(p, q, N) -> (r, coeff)

Commutator [Pp, Pq] = coeff · Pr. coeff = 0 if the strings commute, else 2·(phase of Pp P_q). Two Pauli strings always commute or anticommute, so the commutator is one string.

Examples

julia> _, coeff = pauli_comm((UInt64(1), UInt64(0)), (UInt64(1), UInt64(0)), 1);  # [X, X]

julia> coeff == 0    # commuting strings
true

Ladder Strings and Weight Sectors

The ladder representation stores each site as I/σ⁺/σ⁻/Z in a (t, s) tableau. A ladder string carries a definite coherence order, the spin weight w = #σ⁺ - #σ⁻ (lweight), which a Cartesian string does not; fixing w is an exact block of the Sz-conserving Liouvillian, a further ~3-8x on top of grade truncation. The price is that a ladder product is no longer one string (σ⁺σ⁻ = (I + Z)/2) so [`laddermult](@ref) returns a *sum* of strings. A distinct [LadderLabel`](@ref) type keeps the two tableaux from being mixed at the type level.

RestrictedSpinDynamics.LadderLabel — Type
LadderLabel(t, s)

A ladder string on ≤ 64 spins as a (t, s) bitmask pair. Per site: I=(0,0), σ⁺=(1,0), σ⁻=(1,1), Z=(0,1). isbits, hashable, and totally ordered so it drops into the same DictIndex/SortedIndex backends as PauliLabel. A distinct type from PauliLabel on purpose: it keeps the (t,s) and (x,z) tableaux apart at the type level, so mixing the two representations is caught at compile time.

source
RestrictedSpinDynamics.LADDER_ID — Constant
LADDER_ID

The identity ladder string I ⊗ ... ⊗ I, LadderLabel(0, 0), the unit of ladder_mult.

source
RestrictedSpinDynamics.LadderDict — Type
LadderDict = Dict{LadderLabel, ComplexF64}

A ladder-representation operator as a sum Σ coeff · string. Unlike Pauli strings, a product of two ladder strings is a sum of strings (because σ⁺σ⁻ = ½(I + Z)), so ladder_mult and the weight-sector Liouvillian assembly accumulate into a LadderDict rather than a single string times a phase. The ladder twin of PauliDict.

source
RestrictedSpinDynamics.lgrade — Function
lgrade(p::LadderLabel) -> Int

Grade = number of non-identity sites = popcount(t | s). Ladder twin of grade.

Examples

julia> lgrade(LadderLabel(1, 0))   # a single σ⁺ site
1
source
RestrictedSpinDynamics.lweight — Function
lweight(p::LadderLabel) -> Int

Spin weight (coherence order) w = #σ⁺ − #σ⁻ = popcount(t & ~s) − popcount(t & s), the U(1) charge under z-rotation. Fixing w is an exact block of the Sz-conserving 𝓛 (the sector tag of a ladder [`restrictedbasis`](@ref)), a further ~3-8× reduction on top of grade truncation.

Examples

julia> lweight(LadderLabel(1, 0))   # a single σ⁺
1

julia> lweight(LadderLabel(1, 1))   # a single σ⁻
-1
source
RestrictedSpinDynamics.ladder_mult — Function
ladder_mult(p, q, N) -> LadderDict

Product of two ladder strings as a sum Σ coeff · string (an empty dict = zero). Unlike pauli_mult (one string × phase), a ladder product can span several strings because σ⁺σ⁻ = ½(I+Z); the site products multiply out over the N sites.

Examples

julia> length(ladder_mult(LadderLabel(1, 0), LadderLabel(1, 1), 1))   # σ⁺σ⁻ = ½(I + Z)
2

julia> length(ladder_mult(LadderLabel(1, 0), LadderLabel(1, 0), 1))   # σ⁺σ⁺ = 0
0
source
ladder_mult(p::SparseLadderLabel, q::SparseLadderLabel, N) -> SparseLadderDict

Sparse twin of the ladder product: a SUM of strings (empty dict = zero). Merges the two ascending site lists; at each occupied site applies the single-site ladder product table; identity-on-both sites pass through (not visited). Reproduces the tableau ladder_mult restricted to the union of occupied sites.

source
RestrictedSpinDynamics.ladder_comm — Function
ladder_comm(p::LadderLabel, q::LadderLabel, N) -> LadderDict

Commutator [p, q] of two ladder strings, a LadderDict sum. The ladder-rep bracket twin of pauli_comm; pairs with ladder_mult.

Pauli-to-Ladder Change of Basis

A user-facing operator is built in the Pauli convention (I_a = σ_a / 2) and re-expressed in the ladder basis at the API boundary: I -> I, X -> σ⁺ + σ⁻, Y -> -i σ⁺ + i σ⁻, Z -> Z. An Sz-conserving operator lands on weight-0 strings only; a transverse operator on weight +-1. [`ladderto_pauli`](@ref) inverts the map.

RestrictedSpinDynamics.pauli_to_ladder — Function
pauli_to_ladder(op, N) -> LadderDict

Re-express a Pauli-dict operator in the ladder basis (I→I, X→σ⁺+σ⁻, Y→−iσ⁺+iσ⁻, Z→Z). An S_z-conserving operator maps to weight-0 ladder strings only; a transverse operator maps to weight ±1.

Examples

julia> length(pauli_to_ladder(spin_op(1, 1, 1), 1))   # I_x = ½X → ½σ⁺ + ½σ⁻
2
source
RestrictedSpinDynamics.ladder_to_pauli — Function
ladder_to_pauli(op, N) -> PauliDict

Inverse of pauli_to_ladder: re-express a ladder-basis operator (a LadderDict) in the Pauli basis, per site σ⁺ = ½(X + iY), σ⁻ = ½(X − iY), Z → Z, I → I. Round-trips with pauli_to_ladder.

Examples

julia> ladder_to_pauli(pauli_to_ladder(spin_op(1, 1, 3), 1), 1) == spin_op(1, 1, 3)   # I_z round-trips exactly
true
source

Spherical-Tensor Strings

A spin-$S$ site of dimension $d = 2S+1$ is written not in Pauli operators but in the $d^2$ irreducible spherical tensors $T^k_q$ ($k = 0 \dots 2S$, $q = -k \dots k$), packed one per site into a SpinTensorLabel tableau (B bits per site, so the N <= 64 ceiling relaxes to 64 / B). Like a ladder product, a tensor product is a sum of strings (a cached tensor_table drives each site product), so the Liouvillian stays sparse and every element is a table-driven site product. The string product and bracket are tensor_mult / tensor_comm (both take a radix), the higher-spin twins of pauli_mult / pauli_comm and ladder_mult / ladder_comm. At $d = 2$ the construction reduces exactly to the Pauli one, the standard regression check. Sites of different dimension coexist in one label (mixed radix). spin_matrix and tensor_op build dense and string operators from this basis.

The radix-parameterized basis over these strings is on the Basis & Symmetry page; the higher-spin composers, state constructors, and workflow are in the Higher-Spin guide.

RestrictedSpinDynamics.SpinTensorLabel — Type
SpinTensorLabel{B}

A higher-spin operator string on up to 2*(64 div B) sites, packing a per-site spherical-tensor letter index (0 .. 2^B-1, letter 0 = identity) into B bits per site across a fixed pair of 64-bit words w::NTuple{2,UInt64} (no cross-word straddling). isbits, hashable and totally ordered, so it reuses the same DictIndex/SortedIndex backends as PauliLabel and LadderLabel. B is chosen from the site dimension d = 2S+1 by st_bits (d^2 letters need ceil(log2(d^2)) bits). The product algebra on this label is the higher-spin spherical-tensor workstream; this type is the bit-packing foundation it builds on.

source
RestrictedSpinDynamics.TensorDict — Type
TensorDict{B} = Dict{SpinTensorLabel{B}, ComplexF64}

A higher-spin operator as a sum sum coeff * string. The spin-tensor twin of LadderDict: products expand to sums of strings, so the algebra accumulates into a dict. B is the label's bit-width.

spin_dim(S) -> Int

Site Hilbert dimension d = 2S+1 for spin quantum number S (accepts a Rational such as 1//2 or an integer/float). spin_dim(1//2) == 2, spin_dim(1) == 3.

source
RestrictedSpinDynamics.spin_matrix — Method
spin_matrix(d, axis) -> Matrix{ComplexF64}

Single-site spin operator for a dimension-d site (d = 2S+1) as a dense d x d matrix. axis is :x/:y/:z (or :p/:m for J+/J-, :id for the identity). States are ordered m = S, S-1, ..., -S. The higher-spin analogue of sigma/2, but returning the full d x d matrix (no factor of 1/2: these are Jx, Jy, Jz in units of hbar).

source
RestrictedSpinDynamics.st_bits — Method
st_bits(d) -> Int

Bits per site needed to index the d^2 single-site operators of a dimension-d site (d = 2S+1): ceil(log2(d^2)). d = 2 gives 2 (the Pauli/ladder width), d = 3 (spin-1) gives 4, d = 4 gives 4, d = 5 gives 5.

source
RestrictedSpinDynamics.st_grade — Method
st_grade(p::SpinTensorLabel{B}) -> Int

Grade = number of non-identity sites (letter != 0), the quantity the basis truncates by. Counts nonzero B-bit fields across both words; N-independent since sites past N hold letter 0.

source
RestrictedSpinDynamics.st_rank — Method
st_rank(p, site, tabs) -> Int
st_rank(p, site, radix::AbstractVector) -> Int

Multipole rank k of the spherical-tensor letter that spin-tensor string p carries on site (0 for the identity letter, 1..2S otherwise), read from tabs[site]. Rank is the higher-spin axis absent at spin-1/2: k = 1 is a linear (dipole / magnetization) operator, k = 2 quadrupolar, and so on. Used by dla_report to resolve the dynamical Lie algebra by how far up the multipole ladder it reaches. Pass a radix instead of tabs and the site tables are built for you.

source
RestrictedSpinDynamics.st_weight — Method
st_weight(p, tabs) -> Int
st_weight(p, radix::AbstractVector) -> Int

Total coherence order (spin weight) of a spin-tensor string: sum_k q_k over its letters, with each site's q read from its own tabs[k]. The higher-spin generalization of lweight; the sector tag a weight-restricted tensor basis would carry. Pass a radix (e.g. basis.radix / spin_radix) and the site tables are built for you, so no internal table vector is needed.

RestrictedSpinDynamics.tensor_comm — Method
tensor_comm(p, q, N, tabs) -> TensorDict
tensor_comm(p, q, N, radix::AbstractVector) -> TensorDict

Commutator [p, q] of two spin-tensor strings, a TensorDict sum. The higher-spin bracket twin of pauli_comm; pairs with tensor_mult. Pass a radix and the site tables are built for you.

source
RestrictedSpinDynamics.tensor_mult — Method
tensor_mult(p, q, N, tabs) -> TensorDict

Product of two spin-tensor strings as a sum sum coeff * string (empty dict = zero); site k's product is supplied by tabs[k] (per-site TensorTable, so heterogeneous spin works). A single TensorTable is accepted for uniform spin. Mirrors ladder_mult: a zero site kills the whole product, and E_a E_b may span several letters.

source
RestrictedSpinDynamics.tensor_mult — Method
tensor_mult(p::SparseSpinTensorLabel, q::SparseSpinTensorLabel, N, tabs) -> SparseTensorDict

Sparse twin of the spherical-tensor product: a SUM of strings (empty dict = zero). Merges the two ascending site lists; at each occupied site applies tabs[k].prod; identity-on-both sites pass through. Mirrors the tableau tensor_mult restricted to the union of occupied sites.

source
RestrictedSpinDynamics.tensor_op — Method
tensor_op(N, site_mats, radix) -> TensorDict
tensor_op(N, site_mats, d::Integer) -> TensorDict

Build an N-site tensor-dict operator from per-site dense matrices site_mats (Dict(site => Matrix) or site => Matrix pairs); radix is the per-site dimension vector [d_1, ..., d_N] (or a single d for uniform spin). Each site matrix is decomposed into tensor letters (coeff_a = Tr(E_a^dagger M)/d) and expanded over the touched sites, untouched sites carrying the identity; the label bit-width is max_k st_bits(d_k) so a mixed-radix operator packs into one type. The higher-spin input boundary - supply the site matrices with spin_matrix(d, :z) etc., so no per-term algebra needs re-deriving.

source
RestrictedSpinDynamics.tensor_table — Method
tensor_table(d) -> TensorTable

The cached TensorTable for a dimension-d site (d = 2S+1). Built on first use and reused.

Sparse Labels (N > 64)

The three encodings above pack each site into a fixed-width field, which caps the system at the word size (N <= 64 for Pauli and ladder, 64 / B for tensor). Past that cap each has a sparse grade-scaled twin (SparsePauliLabel, SparseLadderLabel, SparseSpinTensorLabel) that stores only the occupied (site, letter) pairs in ascending-site order, so its size scales with the grade (correlation order) rather than N and the site index is an unbounded UInt32. The product contract is unchanged, a single string times a phase (a sum of strings for ladder and tensor), so pauli_mult / ladder_mult / tensor_mult and the whole Liouvillian stack run identically; the labels are isbits, hashable, and ordered, so they serve DictIndex / SortedIndex / RadixIndex exactly like the tableau labels.

The fixed capacity SPARSE_CAP (default 16) is the largest grade a label can hold; it must cover the largest intermediate product in Liouvillian assembly (max(term grade) + kmax), and a product past it throws a clear capacity error. restricted_basis selects the sparse path automatically for N > 64 (see Basis & Symmetry), so no user call changes. The label types and their sparse_* product and operator builders (in basis/sparse_pauli.jl and its ladder/tensor siblings) are listed in the Source Map.
