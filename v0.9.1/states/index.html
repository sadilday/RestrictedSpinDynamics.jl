The initial density operator, and the composite spin systems the verb layers dispatch on.

State Construction

The state composer is the state-space counterpart of hamiltonian: it builds an initial coefficient vector from named terms projected onto a given RestrictedBasis. The building block is pure, a rank-1 local projector |ψ⟩⟨ψ| (a ket), which subsumes polarized (single-spin kets) and singlet (a correlated pair ket); mixed and bloch cover mixed and arbitrary single-spin states, and the tip modifier rotates a term. On a higher-spin (d ≥ 3) site the dipole terms set only the rank-1 (magnetization) part; aligned adds rank-2 quadrupolar order (deuterium-style alignment) and multipole sets a general spherical-tensor population, with tensor_state the raw per-site-matrix escape hatch. A weighted sum of states ρ = Σ_k w_k ρ_k (the "sum of projectors") is built with mixture:

c = mixture(basis, 0.5 => pure((1, 2), :singlet), 0.5 => mixed(1:2))   # half singlet, half mixed
RestrictedSpinDynamics.aligned — Method
aligned(spins; order = 1.0, axis = :z) -> MultipoleTerm

Rank-2 quadrupolar order (alignment) on each of spins (spin ≥ 1 / d ≥ 3): the state ρ ∝ I + order·T²₀ along axis, i.e. ⟨I⟩ = 0 with ⟨3I_axis² − I(I+1)⟩ ≠ 0 — the deuterium / quadrupolar-order state the dipole builders (polarized / bloch) cannot reach. order is a fraction in [-1, 1] of the maximal physical alignment (±1 sits on the positive-semidefinite boundary; order = -1 on spin-1 is the pure |m = 0⟩ state). For a general multipole population use multipole; for an arbitrary site matrix use tensor_state. Composes with the other state terms over disjoint spins through state.

RestrictedSpinDynamics.mixture — Method
mixture(basis, components...) -> Vector{ComplexF64}

Convex sum of states ρ = Σk wk ρk: the "sum of projectors". Each component is w => spec with weight w and spec either a coefficient Vector (from state/mixture) or one or more state terms (a single term or a tuple of terms). Weights are renormalized to Σk w_k = 1, so the result is trace-1. This is the piece the per-site product terms cannot express: an arbitrary mixed state, a Boltzmann ensemble, or e.g. "half singlet, half mixed".

Examples

julia> b = restricted_basis(1, 1);

julia> mixture(b, 1.0 => pure(1, :up)) == state(b, pure(1, :up))   # one component is just the state
true

julia> c = mixture(b, 0.5 => pure(1, :up), 0.5 => pure(1, :down));  # ρ = ½|↑⟩⟨↑| + ½|↓⟩⟨↓| = I/2

julia> round(real(expect(b, c, spin_op(1, 1, 3))); digits = 6)     # ⟨Iz⟩ = 0 (maximally mixed)
0.0
source
RestrictedSpinDynamics.multipole — Method
multipole(spins, (k, q) => amp, ...) -> MultipoleTerm

General single-site spherical-tensor population on each of spins (spin ≥ 1 / d ≥ 3): ρ = I/d + Σ amp·T^k_q, each T^k_q (0 ≤ k ≤ 2S, −k ≤ q ≤ k) the normalized rank-k order-q multipole. The result must be a physical density matrix — Hermitian (pass conjugate (k, ±q) pairs) and positive-semidefinite (small enough amplitudes), both checked. The low-level twin of aligned (the ergonomic rank-2 case, parameterized by a fraction of maximal); for a raw matrix use tensor_state.

Examples

julia> basis = restricted_basis(1, 1; radix = 3);   # one spin-1 site

julia> c = state(basis, multipole(1, (2, 0) => 0.2));   # longitudinal quadrupolar order

julia> round(real(expect(basis, c, total_spin_op(1, :z, 3))); digits = 10)   # ⟨Iz⟩ = 0
0.0

RestrictedSpinDynamics.pure — Method
pure(spins, ket) -> a rank-1 local projector term

A pure local state |ψ⟩⟨ψ| on spins, the building block behind the "sum of projectors" idiom (compose with mixture, place with state); subsumes polarized and singlet. ket is one of:

  • a single-spin Symbol axis: :up/:down, :x/:y/:z, :minusx/:minusy/:minusz. pure(s, :up) is ½(I+Z).
  • a single-spin amplitude [α, β] (2-vector, normalized): the ket α|↑⟩ + β|↓⟩.
  • a single-spin direction (mx, my, mz) (3-vector, renormalized to the pure |m| = ½).
  • a two-spin correlated symbol when spins is a pair: :singlet ¼(I−XX−YY−ZZ), :triplet0 ¼(I+XX+YY−ZZ), or the product :tripletplus |↑↑⟩ / :tripletminus |↓↓⟩. Grade-2, needs kmax ≥ 2.

On a higher-spin basis (restricted_basis(...; radix)) a single-spin pure(...) is a genuine pure spin-S state (highest-weight |m = S⟩, an SU(2) coherent state, or an explicit length-d ket); the linear polarized/bloch terms stay high-temperature products, and pair kets remain spin-1/2 only.

Examples

julia> b = restricted_basis(2, 2);

julia> state(b, pure(1, :up)) == state(b, polarized(1, :z))          # :up is the +z single-spin projector
true

julia> state(b, pure(1, [1, 0])) == state(b, pure(1, :up))   # amplitude ket |↑⟩
true

julia> count(!iszero, state(b, pure((1, 2), :singlet)))   # correlated pair projector: I, XX, YY, ZZ
4
source
RestrictedSpinDynamics.singlet — Method
singlet(i, j)

Parahydrogen/PHIP singlet on the pair (i,j): ρ_pair = ¼(I − XX − YY − ZZ), rest per the other terms; the correlated case of pure((i,j), :singlet). Needs a Pauli basis with kmax ≥ 2 (grade-2).

Examples

julia> count(!iszero, state(restricted_basis(2, 2), singlet(1, 2)))   # identity + XX, YY, ZZ
4

RestrictedSpinDynamics.state — Method
state(basis, terms...) -> Vector{ComplexF64}

Compose the initial-ρ coefficient vector from named local-state terms (pure, singlet, polarized, mixed, bloch) over disjoint spin subsets. Any spin no term names is maximally mixed (I/2); a term on :rest sweeps up every unnamed spin. The state twin of the hamiltonian(...) / dissipator(...) idiom. For a weighted sum of states ρ = Σk wk ρ_k (a "sum of projectors") use mixture.

On a higher-spin basis (restricted_basis(...; radix)) state builds the per-site density matrices directly: a single-spin pure term becomes a genuine pure spin-S projector (an SU(2) coherent state or an explicit ket), while polarized/mixed/bloch stay linear (high-temperature) products ρ_s = I/d + (3/(S(S+1)d)) Σ_a m_a I_a (the Pauli Bloch state at d = 2). Correlated pair blocks (singlet / :triplet0) are spin-1/2 only and are rejected on a higher-spin basis; pass explicit density matrices via tensor_state instead. Higher-spin support is experimental and its API may change.

Examples

julia> basis = restricted_basis(4, 2);

julia> length(state(basis, polarized(1:4, :z; m = 0.01)))       # every spin thermally +z
67

julia> length(state(basis, singlet(1, 2)))           # PHIP pair, spins 3-4 mixed
67
source
RestrictedSpinDynamics.tip — Method
tip(term, θ; axis=:x)

Ideal hard RF tip of flip angle θ (about axis ∈ (:x,:y,:z)) applied to a state term, the common "polarize, then a pulse" prep, e.g. tip(polarized(1:N, :z), π/2). Rotates the term's Bloch vector analytically; a singlet is rotationally invariant, so tip leaves it unchanged.

Examples

julia> tip(singlet(1, 2), π/2) === singlet(1, 2)   # singlet is rotation-invariant
true

Spin Systems

A SpinSystem bundles a mixed electron / nuclear spec (isotopes, shifts, couplings) into one object the verb layers dispatch on. The quick way in is the isotope-vector or Pair-count form — the isotopes set the gyromagnetic ratios and spins, names default, and shifts default to zero:

ss = SpinSystem(["1H", "1H", "14N"]; couplings = [(1, 3, 52.3), (2, 3, 52.3)])     # two protons + spin-1 14N
ss = SpinSystem("1H" => 2, "14N" => 1; couplings = [(1, 3, 52.3), (2, 3, 52.3)])   # the same, by count

The full keyword constructor (names, isotopes, shifts, gammas, kind, coords, csa) is there when you need explicit control. mean_field_reduce performs the self-consistent mean-field electron elimination, folding a fast-relaxing partner into effective shifts plus a paramagnetic relaxation channel.

RestrictedSpinDynamics.ISOTOPE_GAMMA — Constant

Isotope -> gyromagnetic ratio (rad/s/T). 15N is negative; e- is the free electron.

source
RestrictedSpinDynamics.ISOTOPE_SPIN — Constant

Isotope -> nuclear spin quantum number S (as a Rational); spin_radix reads per-site d = 2S + 1 from this to route higher-spin isotopes (2H, 14N are spin-1) to the tensor basis. e- is the free electron (spin-1/2).

source
RestrictedSpinDynamics.SpinSystem — Type
SpinSystem

Bundled spin-system spec: per-site names, kind (:nucleus / :electron), isotopes, gammas (rad/s/T), shifts (site frequency in Hz), coords (Angstrom, may be empty), the couplings list (i,j,J_Hz) (electron-nucleus entries are hyperfine A), and csa (per-site 3x3 shielding tensor or nothing). Construct with the keyword form (gammas/kind default from isotopes), the isotope-vector form, or the Pair-count shortcut. Consumers dispatch on it: hamiltonian(ss), dipolar_hamiltonian(ss), DipolarRelaxation(ss), CSARelaxation(ss). Higher-spin isotopes route to the tensor basis, and the relaxation models carry over through their relaxation_jumps(model, N, radix) ports (the first-kind dipolar / CSA / scalar forms as high-field closed forms; use redfield_jumps for the rigorous non-secular rate of a higher-spin nucleus).

source
RestrictedSpinDynamics.SpinSystem — Method
SpinSystem(isotopes::AbstractVector{<:AbstractString}; shifts = zeros, names = auto, kwargs...) -> SpinSystem
SpinSystem("1H" => 2, "14N" => 1, ...; kwargs...) -> SpinSystem

Build a system from just its isotope composition: the per-site spin (and so the higher-spin radix) is read from ISOTOPE_SPIN. Shifts default to zero and there are no couplings unless given, so this is the quick way to get a mixed-spin restricted_basis(ss, kmax) without hand-listing sites. Names default to isotope * site-index. The Pair form expands counts, so SpinSystem("1H" => 2, "14N" => 1) is SpinSystem(["1H", "1H", "14N"]). Any keyword of the main SpinSystem constructor (shifts, couplings, coords, csa, ...) may be passed through.

Examples

julia> spin_radix(SpinSystem("1H" => 2, "14N" => 1)) == [2, 2, 3]   # two protons (d=2) + one 14N (spin-1, d=3)
true

RestrictedSpinDynamics.mean_field_reduce — Method
mean_field_reduce(ss::SpinSystem, bath; iz = zeros, chi = zeros, iterate = false,
       run = nothing, tol = 1e-4, maxiter = 50, mixing = 0.4)
    -> (; reduced, extra_jumps, bath_update_hook)                       # iterate = false
    -> (; reduced, extra_jumps, iz, iters, converged, bath_update_hook) # iterate = true

Reduce ss to its active spins by folding the bath subset into a mean field: each bath-active coupling (i,j,J) shifts the active site frequency by J·<Iz_bath> (from iz, default 0), bath-bath couplings drop, active-active couplings are kept and re-indexed. Returns the re-indexed active reduced::SpinSystem, extra_jumps (bath-electron paramagnetic relaxation, wired only with t1e+b0), and bath_update_hook (the active -> bath back-reaction closure).

With iterate = true it closes the self-consistent loop: iz is the pumped baseline and chi the per-site longitudinal susceptibility, so <Iz_f> <- iz_f + chi_f·Σ_a J_fa <Iz_a> (Weiss mean field), and run(reduced, extra_jumps) -> Vector returns one <Iz> per active site each pass. Iterates with damping mixing until the bath <Iz> moves by < tol (or maxiter), also returning iz, iters, converged. This pulls active frequencies from a polarized bath but does NOT transfer polarization (use the SABRE dissipators for that); chi = 0 recovers the one-shot reduction. The ClusterSpec method uses spec.spectator.

RestrictedSpinDynamics.simulate — Method
simulate(ss::SpinSystem, ts; state, kmax = nspin(ss), jumps = [], observables = [],
         verbose = false, io = stdout, leakage = false, dla = false, kwargs...) -> NamedTuple

One-call driver for the whole pipeline from a SpinSystem: build the grade-kmax restricted_basis, hamiltonian(ss), and build_liouvillian with jumps; set the initial state from the state term(s); and propagate over ts, returning its NamedTuple (extra kwargs pass through). Uses the full basis; drop to the explicit layers for a reduced one.

verbose opts into an ORCA-style run log (off by default): :summary prints system / basis / Liouvillian blocks + a final summary; :full (or true) adds per-section timings, a throttled per-step line, and the trace-drift canary. io is the sink (a RunLog tees to a file); leakage/dla add opt-in diagnostic lines (leakage_rate / dla_dimension). Logging is a pure side effect.

Examples

julia> ss = SpinSystem(; names = ["Ha", "Hb"], shifts = [10.0, -10.0], couplings = [(1, 2, 5.0)]);

julia> r = simulate(ss, 0.0:0.1:1.0; state = polarized(1:2, :z),
                    observables = ["mz" => total_spin_op(2, :z)]);

julia> (length(r.ts), round(real(r.traces["mz"][1]); digits = 3))   # total Iz conserved: starts at 1.0
(11, 1.0)

Coupled (Singlet/Triplet) Basis

couple(basis, subset) recouples a subset of spins from the computational (Zeeman) product basis into their total-angular-momentum basis by Clebsch-Gordan recoupling, the singlet/triplet reclassification and its higher-spin generalization. States are classified by total spin S and projection M (the SU(2) irrep), equivalently by the permutation-symmetry irrep via Schur-Weyl (the S_n side is handled by SpinClasses/PointGroup). coupled_op emits the coupled transition operators in the host basis's native representation (Pauli, ladder, or spherical-tensor), and singlet_op / triplet0_op / singlet_order_op gain CoupledBasis methods that reproduce the pair operators; manifold_op is the N-spin total-spin-S projector. coupled_state prepares a coupled eigenstate |S,M⟩ as an initial state — the correlated/entangled analogue of tensor_state that reaches states the product builders cannot (a pure two-spin-1 molecular singlet, say). It is a dense, small-subset readout/preparation/classification lens, not a propagation basis: the coupled operators mix grade (the singlet projector is I/4 − I₁·I₂), so reading a rank-r coupled observable needs kmax ≥ r.

Experimental scope

The current implementation builds only the sequential coupling tree (order = :sequential; other trees, related by 6j/9j recoupling, throw), and the singlet/triplet wrappers cover the two-spin subset only (past the pair use manifold_op, coupled_state, or coupled_op with explicit indices). CoupledState carries the SU(2) labels S, M, tree; the S_n permutation irrep stays with the symmetry layer.

RestrictedSpinDynamics.CoupledBasis — Type
CoupledBasis{L}

The coupled basis of a subset, carrying the change of basis U (columns = coupled states in the uncoupled basis) and the per-state CoupledState labels. L is the host basis's label type, so coupled_op emits in that native representation.

RestrictedSpinDynamics.couple — Method
couple(basis, subset; order = :sequential, tol = 1e-10) -> CoupledBasis

Couple the subset spins of basis into their total-angular-momentum (singlet/triplet) basis by Clebsch-Gordan recoupling, returning a CoupledBasis. The states are classified by total spin S and projection M (the SU(2) irrep), equivalently by the permutation-symmetry irrep via Schur-Weyl (the S_n side is SpinClasses/PointGroup). Built by one diagonalization of the coupling-tree complete set of commuting observables {S²_{1..2}, …, S²_{1..k}, J_z}, so the intermediate spins land in tree.

The transform is dense on the subset (dimension ∏ d_k), a small-subset tool like the AHT layer, and a readout/preparation/classification lens rather than a propagation basis: a coupled operator mixes grade (the singlet projector is I/4 − I₁·I₂, grades 0 and 2), so reading a rank-r coupled observable needs kmax ≥ r. On a symmetry-adapted basis, coupling a subset that splits a magnetic-equivalence orbit interacts with the permutation adaptation (the Schur-Weyl other factor), fine for readout but take the two together.

Experimental

A dense small-subset readout layer, not covered by the v1 stability guarantee. Scope limits of the current implementation: only the sequential coupling tree is built (order = :sequential; the other trees, related by 6j/9j recoupling, throw). The singlet_op/triplet0_op/singlet_order_op CoupledBasis methods are two-spin convenience wrappers; past the pair, use manifold_op (the total-spin-S projector) or coupled_op with explicit indices, and coupled_state to prepare a coupled eigenstate as an initial state. CoupledState carries the SU(2) labels S, M, tree but not the S_n permutation irrep, which stays with SpinClasses/PointGroup.

Examples

julia> cb = couple(restricted_basis(2, 2), [1, 2]);          # two spin-1/2 → singlet ⊕ triplet

julia> sort([(Int(2s.S), Int(2s.M)) for s in cb.states])     # (2S, 2M): one singlet, three triplet
4-element Vector{Tuple{Int64, Int64}}:
 (0, 0)
 (2, -2)
 (2, 0)
 (2, 2)

RestrictedSpinDynamics.coupled_op — Method
coupled_op(cb, a, b) -> native operator dict

The transition operator |a⟩⟨b| of coupled states a, b (indices into cb.states), embedded with identity on the uncoupled sites, in the native representation of the host basis (PauliDict, ladder, or TensorDict). Built by Hilbert-Schmidt projection onto the subset operator basis, so it round-trips through dense_operator.

Examples

julia> using LinearAlgebra: norm

julia> cb = couple(restricted_basis(2, 2), [1, 2]);

julia> s = findfirst(st -> st.S == 0, cb.states);            # the singlet state

julia> norm(dense_operator(coupled_op(cb, s, s), 2) - dense_operator(singlet_op(2, 1, 2), 2)) < 1e-12
true
source
RestrictedSpinDynamics.coupled_state — Method
coupled_state(basis, cb, a) -> Vector{ComplexF64}
coupled_state(basis, cb; S, M) -> Vector{ComplexF64}

Prepare a coupled eigenstate as an initial-state coefficient vector on basis: the subset of cb in the pure coupled state |a⟩ (an index into cb.states, or selected by total spin S and projection M), the uncoupled spins maximally mixed. The correlated/entangled analogue of tensor_state, and the N-spin generalization of state(basis, singlet(i, j)). Grade-truncated like any state: a coupled projector spans grades 0..2S of the subset, so kmax ≥ 2S is needed to retain it.

Examples

julia> b = restricted_basis(2, 2); cb = couple(b, [1, 2]);         # two spin-1/2 -> singlet ⊕ triplet

julia> using LinearAlgebra: norm

julia> norm(coupled_state(b, cb; S = 0, M = 0) - state(b, singlet(1, 2))) < 1e-10   # == the singlet prep
true
