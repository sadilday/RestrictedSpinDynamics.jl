Inference (System ID & State Estimation)

Experimental

RestrictedSpinDynamics.Inference is an experimental inverse-problem layer; its API is not covered by the v1 stability guarantee. See Public API & Stability.

Access

These names are not brought in by using RestrictedSpinDynamics. Reach them with using RestrictedSpinDynamics.Inference (then fit, uncertainty, smooth, ... are in scope), or call them qualified as RestrictedSpinDynamics.Inference.fit.

RestrictedSpinDynamics.Inference estimates the generator's structural parameters or the state from measured FIDs, and reports the Cramer-Rao uncertainty. The theory (the estimator, the Fisher geometry, identifiability, model selection, the parameter/state duality, and the Leggett-Garg test) is in Inference and System Identification; this page is the API reference.

fit returns one fit-result NamedTuple. Read it with the cost/loglik/residuals accessors (and rss/nobs, derived from residuals), and take the Cramer-Rao error bars from the uncertainty NamedTuple. The diagnostics info_criteria, fit_report, and multistart accept any fit result. fit runs two ways: a joint structural fit over several conditions, and a separable (VARPRO) fit through a Separable spec, which concentrates out the per-component amplitudes of a multi-line FID.

A direct hsvd line estimator supplies seed-free frequency/damping estimates to start a structural fit (the time-domain least-squares is otherwise multimodal in the frequencies); flat_prior regularizes only the flat Fisher directions of a rank-deficient fit; and noise_weights sets the inverse-variance weighting from a signal-free FID tail.

A Worked Fit

Synthesize a noisy FID from a known two-spin system, then recover its coupling and dephasing rate with Cramér-Rao error bars.

using RestrictedSpinDynamics, RestrictedSpinDynamics.Inference, Random

N = 2
basis = restricted_basis(N, N)

# a known two-spin system: a 5 Hz offset, a 6 Hz J-coupling, and dephasing
Ltrue = build_liouvillian(basis, hamiltonian(zeeman(N, [0.0, 5.0]), jcoupling(N, 1, 2, 6.0));
                          jumps = dephasing(N, 1:N, 1.0))
c0 = ComplexF64.(state(basis, polarized(1:N, :x)))
ts = collect(0.0:0.01:0.5)
Sp = reduce(op_add, [spin_pm(N, s, +1) for s in 1:N])          # the detected ⟨I+⟩

# synthesize a noisy measured FID
clean = propagate(basis, Ltrue, c0, ts; observables = ["Ip" => Sp]).traces["Ip"]
Random.seed!(1); σ = 0.02
fid = clean .+ σ .* (randn(length(ts)) .+ im .* randn(length(ts)))

# fit the coupling and the dephasing rate back (the unit terms are the parameter handles)
data = (mod = modulation(N, hamiltonian(zeeman(N, [0.0, 5.0]))), c0 = c0, ts = ts, op = Sp,
        target = fid, weights = 1/σ^2)
r = fit(basis, [data], Any[jcoupling(N, 1, 2, 1.0) => 3.0, dephasing(N, 1:N, 1.0) => 0.3];
        optimizer = :natural, iters = 40, uncertainty = true, σ = σ)

(J = round(r.params[1]; digits = 3), R2 = round(r.params[2]; digits = 3),
 stderr = round.(r.uncertainty.stderr; digits = 3))         # true J = 6.0, R2 = 1.0
(J = 5.986, R2 = 1.016, stderr = [0.018, 0.04])
RestrictedSpinDynamics.Inference — Module
RestrictedSpinDynamics.Inference

The inverse-problem layer: estimate parameters or states from measured FIDs. Fit one shared physical model to several FIDs jointly (fit), separable multi-component VARPRO fits (fit with a Separable spec), Cramér-Rao uncertainty and identifiability (uncertainty, with null-space regularization of the flat directions via flat_prior), model selection (info_criteria, multistart, fit_report), and state estimation (tomography, the moving-horizon smooth / moving_horizon / step!). A direct hsvd line estimator seeds the fit without a starting guess, and noise_weights sets the inverse-variance weighting from a signal-free FID tail. Every fitter returns the fit-result NamedTuple (read via the cost/loglik/residuals accessors); its Cramér-Rao payload is the uncertainty NamedTuple. Reached qualified as RestrictedSpinDynamics.Inference.* (not re-exported), the submodule uses the control.jl adjoint for the exact per-condition structural gradient.

The theory (the estimator and its Fisher geometry, identifiability, model selection, the parameter/state duality, and the macrorealism test) is on the Inference and System Identification page.

RestrictedSpinDynamics.Inference.Condition — Type
Condition

A measured FID in a fit: one or more detected channels and their noise weights. Fields:

  • mod, c0: the Liouvillian modulation and initial state; both nothing for a separable fit, which builds its component models from the build closure.
  • ts: the sample times.
  • ops, targets: the per-channel observable covectors and complex target series.
  • weights: the per-channel precision 1/σ².
  • loss, delta: the per-sample loss (:l2 or :huber) and its Huber knee.

Build one directly, or pass a NamedTuple to fit; a single op/target and a scalar weights are expanded per channel.

RestrictedSpinDynamics.Inference.GaussianPrior — Type
GaussianPrior(mean, precision)

A Gaussian prior or arrival cost ½(x-mean)ᵀ Λ (x-mean). precision is a scalar λ for an isotropic ridge Λ = λI, or a full information matrix Λ. It fills two roles:

  • the structural ridge in fit, with mean = θ_prior and a scalar precision = λ;
  • the state arrival cost in smooth and moving_horizon, with mean = z̄ and a matrix precision = Λ̄.

Build one from information-form (η, Λ) with info_prior.

RestrictedSpinDynamics.Inference.Separable — Type
Separable(ncomp, build, θ0)

Model spec that selects the separable (variable-projection, VARPRO) fit method. The FID is modeled as Σ_{m=1}^{ncomp} a_m g_m(t; θ): the complex amplitudes a_m are concentrated out by linear least squares, and the shared nonlinear parameters θ (frequencies, rates, couplings) are optimized. build(θ, cond) -> Vector returns the ncomp component models at θ, each a (modulation, c0) pair. θ0 is the nonlinear-parameter start.

RestrictedSpinDynamics.Inference.fit — Method
fit(basis, conditions, structural;
    iters = 200, optimizer = :natural, lr = 0.05, lr_schedule = nothing, tol = 0.0, patience = 8,
    bounds = nothing, prior = nothing, method = :first_order, jac = :forward, damping = 1e-2,
    uncertainty = false, σ = nothing, verbose = false)
    -> (; params, terms, amplitudes, cost, loglik, residuals, history, gradnorm, sigma, uncertainty, meta)

Fit one shared set of structural parameters to several measured FIDs at once (joint system identification). structural = [term_i => θ0_i, ...] lists the shared parameters and their initial guesses. Each entry of conditions is one measured FID, a NamedTuple (; mod, c0, ts, op, target[, weights, loss, delta]) or a Condition.

Options:

  • optimizer: :natural (default, Gauss-Newton / Levenberg-Marquardt) or :adam.
  • bounds: clamp each θ; (0.0, Inf) keeps a rate ≥ 0.
  • prior::GaussianPrior: a ridge for the MAP estimate.
  • uncertainty = true: attach Cramér-Rao error bars. Supply a noise σ, or let it be estimated.

Read the result through cost, loglik, and residuals (rss/nobs derive from residuals). See Inference and System Identification for the estimator and its identifiability geometry.

Example

N = 2
basis = restricted_basis(N, N)

drift = modulation(N, hamiltonian(zeeman(N, [0.0, 5.0])))           # two spins, fixed offset
start = product_state_coeffs(basis; mags = [(1, 0, 0), (1, 0, 0)])  # both along x
ts    = collect(0:0.01:0.4)

data = (mod = drift, c0 = start, ts = ts, op = spin_pm(N, 1, +1), target = fid)  # measured <I+>; fid is your data

Jterm = jcoupling(N, 1, 2, 1.0)        # unit terms; the => value is the initial guess
Gterm = dephasing(N, 1:N, 1.0)
r = fit(basis, [data], [Jterm => 1.0, Gterm => 0.2]; optimizer = :natural, iters = 40, uncertainty = true)

r.params                                     # fitted [J, Γ]
cost(r), loglik(r)                           # misfit, log-likelihood
println(fit_report(r; names = ["J", "Γ"]))   # estimates ± σ, flat directions

RestrictedSpinDynamics.Inference.fit_report — Method
fit_report(result; names = nothing) -> String

Format a fit result (run with uncertainty = true) or a bare uncertainty payload as a readable report. The report shows:

  • each parameter's estimate ± Cramér-Rao σ, with its percent error;
  • the Fisher spectrum, with flat (unresolved) directions flagged and their dominant parameter combination;
  • the correlation matrix, for ≤ 6 parameters.

names labels the parameters.

RestrictedSpinDynamics.Inference.flat_prior — Method
flat_prior(basis, conditions, structural; σ, mean = nothing, rtol = 1e-3, ridge = nothing,
           jac = :forward) -> GaussianPrior

Tikhonov prior that ridges only the flat (unidentifiable) directions of the Fisher information at structural, leaving the identifiable directions free. Eigendecomposes the Fisher F (via uncertainty); a direction with eigenvalue below rtol · λ_max is flat. The returned GaussianPrior has precision Λ = ridge · Σ_flat vᵢ vᵢᵀ. Its mean is the assumed value along the flat directions, defaulting to the current structural values to pin them in place. ridge defaults to rtol · λ_max, the smallest resolved scale.

Pass it to fit as prior to regularize a rank-deficient fit on its null space only, e.g. the homogeneous/inhomogeneous T2 split, where their sum is still fit freely.

RestrictedSpinDynamics.Inference.hsvd — Method
hsvd(fid, dt; order = nothing, rtol = 1e-2)
    -> (; freqs, damping, amplitudes, poles, order, singular_values)
Experimental

Part of the Inference line-estimation layer; not covered by the v1 stability guarantee.

Estimate the lines of a complex free-induction decay fid sampled at interval dt, with no cost function and no starting guess. Models the signal as a sum of damped complex exponentials Σ_k a_k exp((i 2π f_k - λ_k) t) and recovers them by a Hankel-matrix SVD and the pole shift-invariance (HSVD / matrix pencil). Returns the line freqs (Hz), damping (1/T2*), complex amplitudes, the signal poles z_k, the model order, and the Hankel singular_values; lines are sorted by |amplitude|. With order = nothing the order is the count of singular values above rtol · σ_max.

Use it to seed a structural fit, whose time-domain least-squares is multimodal in the frequencies: read the line offsets and splittings for the initial couplings and rates.

Example

l = hsvd(fid, dt)                                       # line table (seed-free, no peak-picking)
# seed a structural fit from the recovered lines (weak-coupling mapping):
fit(basis, conds, Any[off_term => l.freqs[1], jcoup_term => abs(l.freqs[2] - l.freqs[1]),
                      r2_term => sum(l.damping)/length(l.damping)])

RestrictedSpinDynamics.Inference.info_criteria — Method
info_criteria(result; k = length(result.params)) -> (; rss, n, k, aic, aicc, bic)

Information criteria for model selection from a fit result (uses residuals). Treats the complex residuals as n = 2·(#samples) real Gaussian observations, with RSS = Σ|r|² and Gaussian log-likelihood ℓ = -n/2·log(RSS/n) (up to a constant). Returns the Akaike (aic), small-sample-corrected (aicc), and Bayesian (bic) criteria.

Lower is better; compare candidate models on the same data. An extra parameter earns its place only when it lowers aicc/bic, not when it lowers rss alone. bic is the large-sample limit of -2 log Z, the Bayesian evidence.

RestrictedSpinDynamics.Inference.leggett_garg — Method
leggett_garg(basis, L, Q, times; state = nothing, sigma = 0.0)
    -> (; K3, correlators, bound, luders, violation, margin, sigma_K, pK, q2)
Experimental

Part of the Inference Leggett-Garg layer; not covered by the v1 stability guarantee.

Test macrorealism on a time-invariant Liouvillian L for a dichotomic observable Q (a PauliDict) measured at three times. K3 = C12 + C23 - C13 comes from the normalized two-time regression correlators, computed by quantum regression through propagate. state is the initial coefficient vector (default maximally mixed I/d). Returns:

  • bound: the macrorealist limit K3 ≤ 1.
  • luders: the quantum maximum 3/2.
  • violation, margin: K3 > 1 and K3 - 1.
  • pK, sigma_K: with per-correlator measurement noise sigma, the posterior P(K3 > 1) that the data refutes macrorealism, and its spread √3·sigma.
  • q2: the normalization check ⟨Q²⟩ ≈ 1.

For the correlator formula, the Lüders bound, and the decoherence-driven transition to K3 < 1, see Inference and System Identification.

Noninvasiveness

The inequality assumes noninvasive measurability. This is the ideal regression correlator (no intermediate collapse); a real projective protocol faces the measurement-disturbance loophole, handled experimentally.

Example

N = 1
basis = restricted_basis(N, N)
L  = build_liouvillian(basis, spin_op(N, 1, :x))                 # H = Iₓ: σz precesses about x
lg = leggett_garg(basis, L, spin_op(N, 1, :z), (0.0, π/3, 2π/3)) # σz at the Lüders-optimal times
lg.K3          # 1.5, the Lüders bound (classical bound is 1)
lg.violation   # true: coherent evolution breaks macrorealism (decoherence pulls K3 below 1)

RestrictedSpinDynamics.Inference.moving_horizon — Method
moving_horizon(basis, L, ops, dt; window, Q = 1e-4, weights = 1.0, trace = 1.0, ridge = 1e-9,
               prior = nothing, B = nothing) -> MovingHorizon

Construct a recursive MHE filter for the time-invariant Liouvillian L, with observables ops measured every dt. Parameters:

  • window: the number of steps in the sliding window.
  • Q: the process noise (scalar × I).
  • weights: the per-channel measurement precision 1/σ².
  • trace: the trace constraint Tr ρ.
  • ridge: a small regularizer on the window solve.
  • prior::GaussianPrior: seeds the arrival cost; the default is unit information Λ0 = I, which bounds the unobservable directions.
  • B: the continuous input map of ċ = L c + B u. Pass it to fold a known control into the estimate; step!(mh, y, u) then accounts for the applied u.

Recursive MHE is Bayesian updating in information form; see Inference and System Identification.

Example

N = 2
basis = restricted_basis(N, N)
L  = build_liouvillian(basis, hamiltonian(jcoupling(N, 1, 2, 1.0)))
mh = moving_horizon(basis, L, [spin_pm(N, 1, +1)], 0.02; window = 20)
for y in measurements          # measured <I+>, one per dt
    est = step!(mh, y)
    est.estimate               # current coefficient estimate
end

RestrictedSpinDynamics.Inference.moving_horizon — Method
moving_horizon(basis, mod::Modulation, ops, dt; window, t0 = 0.0, Q = 1e-4, weights = 1.0,
               trace = 1.0, ridge = 1e-9, prior = nothing, krylov_m = 30) -> MovingHorizonTD
Experimental

Part of the Inference state-estimation layer; not covered by the v1 stability guarantee.

Time-dependent recursive MHE, the Modulation form of moving_horizon. The known drives make the generator vary over the window, so there is no cached propagator. Each step! solves the current window with smooth, propagating per interval under mod and using the carried arrival cost as its prior; the slide then advances that arrival cost one interval and rolls the absolute-time cursor t0. ops are measured every dt over a sliding window of steps; t0, Q, weights, trace, ridge, and prior match the time-invariant method. Absolute t0 matters, since the drive envelopes are sampled at true time. See Inference and System Identification.

RestrictedSpinDynamics.Inference.multistart — Method
multistart(fitfn, inits) -> (; best, runs, spread)

Run fitfn(init) from each starting point in inits. Returns the lowest-cost run as best, all runs, and the per-parameter spread (the standard deviation of the recovered params across starts). RestrictedSpinDynamics.Inference.noise_weights — Method
noise_weights(fid; nbaseline = max(8, length(fid) ÷ 10), σ_floor = 1e-12) -> (; sigma, weight)

Estimate the per-quadrature detection noise sigma from the signal-free tail of a complex FID (the last nbaseline samples, where the signal has decayed), and return it with the inverse-variance weight = 1/sigma^2 for a noise-aware fit or smooth. The real and imaginary channels share one sigma; σ_floor guards against a zero estimate on a noiseless tail.

Example

nw = noise_weights(fid)                         # σ off the signal-free tail
fit(basis, conds, structural; σ = nw.sigma)     # noise-aware fit; smooth(...; weights = nw.weight) likewise

RestrictedSpinDynamics.Inference.smooth — Method
smooth(basis, mod, ts, ops, targets; weights = 1.0, loss = :l2, delta = 1.0, prior = nothing,
       trace = 1.0, ridge = nothing, krylov_m = 30) -> (; state0, trajectory, information, residual)

One-window moving-horizon smoother. Estimate the window-start state z = c(ts[1]) from the windowed, incomplete, noisy measurements targets and the known dynamics mod, subject to Tr ρ = trace, by information-form weighted least squares; channel c of targets is the series ⟨ops[c]⟩ over ts. Returns:

  • state0: the estimated window-start state.
  • trajectory: the smoothed trajectory over ts.
  • residual: the fit residual.
  • information: the posterior precision Λ = Λ̄ + Σ w aaᵀ, the arrival cost for the next window.

weights is the measurement precision 1/σ² (larger trusts a sample more; 0 ignores it), one of:

  • a scalar: uniform over every channel and sample;
  • a length-nch vector: one precision per channel (observable), applied to all its samples;
  • an nch × length(ts) matrix: a precision per (channel, sample). A zero column is a measurement gap, an unobserved time the smoother fills from the dynamics. Per-sample weighting needs a matrix even for one channel; a length-length(ts) vector is read as per-channel and must match nch.

loss is the per-sample loss:

  • :l2 (default): weighted least squares;
  • :huber: robust, iteratively reweighted least squares. The window is re-solved a few times with each sample scaled by min(1, delta/|residual|), so a few outliers do not drag the estimate. delta is the knee in the residual's units (set it to a few × the noise σ, e.g. 4 * noise_weights(fid).sigma). It is the same robust loss fit applies to parameters, here on the state estimate.

An optional arrival cost prior::GaussianPrior (mean = z̄, precision = Λ̄) carries information from before the window. See Inference and System Identification for the geometry it solves.

Examples

W = fill(1/σ^2, length(ops), length(ts)); W[:, gap] .= 0    # per-sample precision, zero where there is no data
smooth(basis, mod, ts, ops, fids; weights = W)                            # fill an unobserved interval (a gap)
smooth(basis, mod, ts, ops, fids; weights = [1/σx^2, 1/σy^2])             # per-channel precision
smooth(basis, mod, ts, ops, fids; weights = W, loss = :huber, delta = 4σ) # robust to outlier samples

RestrictedSpinDynamics.Inference.step! — Function
step!(mh::MovingHorizon, y, u = Float64[]) -> (; estimate, covariance, uncertainty, information)

Advance the recursive filter by one measurement y (per-channel vector) and the control u applied over the step that follows it (empty for the free filter; requires B passed to moving_horizon). Slides the window, re-solves it against the accrued arrival cost (constrained to the trace), and advances the arrival cost (fold the leaving measurement, predict one step with Q, applying the leaving control). The known control contribution o_cᵀ sⱼ (sⱼ = accumulated Γu over the window) is subtracted from each measurement before the least-squares, and added back to reach the current time. Returns the current-time state estimate, its covariance, a scalar uncertainty (trace of the covariance on the observed subspace), and the information.

RestrictedSpinDynamics.Inference.tomography — Method
tomography(basis, observables, values) -> (; coeffs, residual, rank, dim, condition, complete)

Reconstruct the restricted-basis coefficient vector c (ρ = Σ cα Pα) from measured expectations values[i] = ⟨observables[i]⟩ by least squares, solving M c = y whose rows are the observable covectors. Returns:

  • coeffs: the reconstructed c.
  • residual: ‖M c - y‖.
  • rank, dim, condition: the rank, basis dimension, and conditioning of M.
  • complete: whether the observable set is informationally complete (rank == dim).

Include the identity (value = 1) to pin the trace, and pass an informationally-complete observable set for a physical reconstruction. See smooth for the dynamic case, and Inference and System Identification for the state-estimation geometry, where the Gram MᵀM is the Fisher.

Example

N = 1
basis = restricted_basis(N, 1)
Id   = PauliDict(pauli_label(N) => 1.0 + 0im)                    # identity pins the trace
ops  = [Id, spin_op(N, 1, :x), spin_op(N, 1, :y), spin_op(N, 1, :z)]
vals = [1.0, 0.3, 0.0, 0.4]
t = tomography(basis, ops, vals)
t.complete     # true: informationally complete
t.coeffs       # reconstructed ρ = Σ c_α P_α

RestrictedSpinDynamics.Inference.uncertainty — Method
uncertainty(basis, conditions, structural; σ, jac = :forward, prior = nothing)
    -> (; stderr, covariance, correlation, fisher, condition, identifiability)

Cramér-Rao parameter uncertainty for a joint FID fit at structural = [term_i => θ_i, ...], from the Fisher F = Jacᵀ diag(1/σ²) Jac. σ is the detection-noise standard deviation, a scalar (homoscedastic) or one entry per condition (heteroscedastic). jac selects the Jacobian: :forward (forward sensitivity, default), :frechet (exact dense), or :findiff (central finite differences). Returns:

  • stderr: the per-parameter standard error √diag(F⁻¹).
  • covariance, correlation: the parameter covariance and correlation matrices.
  • fisher, condition: the Fisher F and its condition number.
  • identifiability: eigen(F); near-zero eigenvalues mark flat (unresolved) directions.

The inverse goes through the eigendecomposition with a floor, so a flat direction gives a bounded (large) variance instead of an error. An optional prior::GaussianPrior (e.g. from flat_prior) adds its precision Λ to the Fisher, so covariance/stderr become the posterior (MAP) values and a regularized flat direction reports a finite bar. See Inference and System Identification for the Fisher geometry.
