Time Propagation

Advancing the linear evolution $\dot{c} = \mathcal{L} c$ on the assembled Liouvillian $\mathcal{L}$.

    • Variations

  • GPU Backend

Primary Loop

        propagate(basis, generator, c0, ts; dt, method, backend, ...)
                                 |
                                 v
              choose the generator and engine   (see Variations)
                                 |   constant sparse L, :krylov CPU  (the default)
                                 v
              c = c0;   substep = dt, or the sample spacing if dt is unset
                                 |
                                 v
                     ts[1] > 0 ?  --yes-->  advance c to ts[1]
                                 |
                                 v
                     record!(1)      write <observables> at t0
                                 |
                                 v
     +=============  for each sample  i = 2 .. length(ts)  =============+
     |   dt_i = ts[i] - ts[i-1];    L = Lat(i)                          |
     |                       |                                          |
     |                       v                                          |
     |   split dt_i into  nsub = ceil(dt_i / substep)  sub-steps        |
     |                       |                                          |
     |                       v                                          |
     |     +--------  each sub-step, size h = dt_i / nsub  --------+     |
     |     |   ||L c|| ~ 0 ?  --yes-->  skip (already stationary)  |     |
     |     |         | no                                          |     |
     |     |         v                                             |     |
     |     |   c <- expv(h, L, c)          (matrix-free Krylov)    |     |
     |     |         | MethodError = Arnoldi breakdown             |     |
     |     |         +------>  c <- exp(h L) c   (dense, cached)    |     |
     |     |         |                                             |     |
     |     |         v                                             |     |
     |     |   drift_check ?   track  |Tr rho - 1|                 |     |
     |     +-------------------------------------------------------+     |
     |                       |                                          |
     |                       v                                          |
     |   record!(i)     <observables>;  trajectory?;  progress?         |
     +=================================================================+
                                 |
                                 v
                 return (ts, traces, drift, trajectory)

Variations

The loop above is the default path. Different objects are handled according to the following parameters:

  • Generator (what you hand propagate). A prebuilt sparse L runs the loop directly; an H::PauliDict is assembled into L first, and adaptive = true grows/shrinks the basis between blocks (propagate_adaptive). A Modulation, a Vector{Segment}, an SLE pair (Ls, W), or a SymmetryBlocks dispatches to propagate_modulation / propagate_sequence / propagate_sle / propagate_blocks instead (see Reachability, Control, and the Adaptive Basis).
  • Engine. :krylov on CPU is shown; :dense replaces the whole stepping loop with one $\exp(t_k \mathcal{L})\, c_0$ per sample (propagate_dense); :gpu runs the same loop on the device (propagate_gpu).
  • Per-interval generator (the Lat(i) slot). Constant $\mathcal{L}$ for a plain run; the piecewise-constant hold $\mathcal{L}_0 + \sum_j r_j(i)\, D_j$ for propagate_timedep; or the live, state-dependent $\mathcal{L}(t, c)$ for feedback (zero-order hold, or a Heun predictor-corrector).
  • Instrumentation (all off by default). drift_check records the largest trace deviation $|\mathrm{Tr}\,\rho - 1|$ over the sub-steps, returned as drift; save_trajectory stores the coefficient vector at each sample; progress calls a function at each sample (used by Run Logging).

Propagators and Direct Readouts

propagate is generally a fixed-dt matrix-free Krylov expv of the sparse Liouvillian. The generator is non-normal, so eigendecomposition is unreliable; hence the matrix-free exponential action. propagate_dense is the dense matrix-exponential reference and propagate_timedep handles a time-dependent generator. Two methods skip full integration entirely: steady_state solves the Lindbladian fixed point $\mathcal{L} c = 0$ directly, and initial_rate reads a relaxation rate from the dissipator slope at $t = 0$ (the multiscale idiom, see Relaxation Backends). Pulse-sequence and shaped / feedback control are on Reachability, Control, and the Adaptive Basis.

RestrictedSpinDynamics.commutator_super — Method
commutator_super(basis, H; check_sector = true) -> superoperator

The bare coherent superoperator -i[H, .] on the coefficient vector, i.e. build_liouvillian with no jumps. Use it to build a reusable time-varying Hamiltonian term for propagate_timedep (the coherent twin of the unit-rate dissipator idiom). check_sector=false when H has transverse terms on a coherence-order-restricted basis.

Examples

julia> basis = restricted_basis(2, 2);

julia> H = hamiltonian(jcoupling(2, 1, 2, 5.0));

julia> commutator_super(basis, H) == build_liouvillian(basis, H)
true

RestrictedSpinDynamics.field_ramp — Method
field_ramp(basis, N, unit_freqs, Bof_t, ts; check_sector = true) -> (D_zee, rate_ts)

Package an adiabatic magnetic-field sweep for propagate_timedep: returns a unit-field Zeeman commutator superoperator and the field series B(t). unit_freqs[s] is the site's gyromagnetic ratio in Hz/T, so the returned D_zee scaled by Bof_t(t) (Tesla) is -i[H_Z(B(t)), .]. Splat into propagate_timedep(basis, L_coh, [D_zee], rate_ts, c0, ts; ...).

Examples

N = 4                                            # 2 hydride + 2 substrate spins
basis = restricted_basis(N, 2)
γ = [γH, γH, γ15N, γ15N]                          # Hz/T per site (heteronuclear)
L_coh = build_liouvillian(basis, hamiltonian(jcoupling(N, 1, 2, -7.0), ising(N, 2, 3, J_relay)))
ts = 0.0:0.1:20.0
D, rate_ts = field_ramp(basis, N, γ, linear_ramp(1e-3, 5e-3, 0.0, 20.0), ts)
res = propagate_timedep(basis, L_coh, [D], rate_ts, state(basis, singlet(1, 2)), ts;
                        observables = ["S12" => singlet_op(N, 1, 2),
                                       "S34" => singlet_op(N, 3, 4)])   # watch the transfer

RestrictedSpinDynamics.initial_rate — Method
initial_rate(basis, L, c0, obs; relative = true) -> Float64
initial_rate(basis, L, c0, obs::AbstractVector) -> Vector{Float64}

Initial relaxation rate of ⟨obs⟩ from the dissipator at t = 0, without propagating: R = -Re⟨obs, L c0⟩ / Re⟨obs, c0⟩, the exponential rate in ⟨obs⟩ ~ exp(-R t) (relative = false returns the bare slope -d⟨obs⟩/dt|₀). One L c0 instead of a stiff integration: the multiscale readout for a T1/T2-vs-field sweep with redfield_jumps. The vector method forms one L c0 for many observables, giving a cross-relaxation-matrix row; use relative = false for a cross channel that starts at zero.

Examples

julia> b = restricted_basis(1, 1);

julia> L = build_liouvillian(b, PauliDict(); jumps = decay(1, 1:1, 2.0));

julia> round(initial_rate(b, L, state(b, polarized(1, :z)), spin_op(1, 1, 3)); digits = 4)   # ⟨Iz⟩ decay rate
4.0

linear_ramp(B0, B1, t0, t1) -> (t -> B)

RestrictedSpinDynamics.propagate — Method
propagate(basis, L, c0, ts; observables, dt=nothing, method=:krylov, backend=:cpu, ...) -> NamedTuple

Propagate ρ = Σ cα Pα under the sparse Liouvillian L by fixed-dt Krylov expv stepping, evaluating each observables (name => PauliDict) on ts. Because 𝓛 is non-normal its eigendecomposition is unreliable, so the stepper is matrix-free (only the sparse matvec 𝓛·v) and krylov_m is held fixed.

method=:dense uses the matrix-exp reference (propagate_dense); backend=:gpu the CUDA path (propagate_gpu; precision, device). drift_check adds a per-step trace-drift canary, and progress is a per-sample callback (Krylov CPU path) that simulate uses for its live log.

propagate is also the unified verb: it dispatches on the generator TYPE, a Hamiltonian PauliDict (with jumps, adaptive), a Modulation, a Vector{Segment}, an SLE (Ls, W), or a SymmetryBlocks, to the matching propagate_*. Returns (; ts, traces, ...); fields beyond ts, traces depend on the generator (see Public API & Stability).

Examples

julia> basis = restricted_basis(3, 2);

julia> L = build_liouvillian(basis, hamiltonian(jcoupling(3, 1, 2, 5.0)); jumps = dissipator(decay(3, 1:3, 1.0)));

julia> c0 = state(basis, polarized(1:3, :z));

julia> res = propagate(basis, L, c0, 0.0:0.5:1.0; observables = ["mz" => total_spin_op(3, 3)]);

julia> round(real(res.traces["mz"][end]); digits = 4)   # ⟨Sz⟩ decayed from 1.5
-0.3964
source
RestrictedSpinDynamics.propagate_dense — Method
propagate_dense(basis, L, c0, ts; observables, save_trajectory=false)

Reference propagation by matrix exponential: forms the single-step propagator P = exp(dt·L) once (dt = the uniform ts spacing), then advances c ← P·c across the grid. Deliberately not an eigendecomposition: 𝓛 is non-normal, so its eigenvectors can be badly conditioned; the matrix exponential and Krylov expv avoid forming them and agree.

Examples

julia> basis = restricted_basis(3, 2);

julia> L = build_liouvillian(basis, hamiltonian(jcoupling(3, 1, 2, 5.0)); jumps = dissipator(decay(3, 1:3, 1.0)));

julia> c0 = state(basis, polarized(1:3, :z));

julia> res = propagate_dense(basis, L, c0, 0.0:0.5:1.0; observables = ["mz" => total_spin_op(3, 3)]);

julia> round(real(res.traces["mz"][end]); digits = 4)
-0.3964

RestrictedSpinDynamics.propagate_timedep — Method
propagate_timedep(basis, L_base, Ds, rate_ts, c0, ts; observables,
                  dt=nothing, save_trajectory=false,
                  drift_check=false, drift_tol=1e-8, krylov_m=30)

Propagate under a Liouvillian with time-varying dissipative rates, 𝓛(t) = L_base + Σⱼ rⱼ(t)·Dⱼ, by piecewise-constant (zero-order-hold) Krylov stepping. L_base is the constant part; each Ds[j] is a unit-rate dissipator superoperator and rate_ts[j] is rⱼ sampled on ts. Exact for a piecewise-constant rate (the dissipator is linear in its rate). Returns the same NamedTuple as propagate.

Examples

julia> basis = restricted_basis(2, 2);

julia> Lb = build_liouvillian(basis, hamiltonian(jcoupling(2, 1, 2, 5.0)));

julia> D = build_liouvillian(basis, PauliDict(); jumps = [(collective_pm(2, 1:2, -1), 1.0)], check_sector = false);

julia> c0 = state(basis, polarized(1:2, :z));

julia> res = propagate_timedep(basis, Lb, [D], [[0.0, 1.0, 2.0]], c0, 0.0:0.5:1.0; observables = ["mz" => total_spin_op(2, 3)]);

julia> length(res.ts)
3

RestrictedSpinDynamics.rate_vs_field — Method
rate_vs_field(basis, fields, make_L, c0, obs; relative = true) -> (; fields, rates)

Relaxation rate of ⟨obs⟩ across a field sweep, read from the generator without propagating: the sweep_field whose readout is initial_rate. For each B in fields, make_L(B) returns the Liouvillian at that field. A single obs gives a Vector of rates (the T1/T2 dispersion); a vector of observables gives a Vector{Vector}, one cross-relaxation-matrix row per field. make_L carries the whole field-dependence and may rebuild redfield_jumps in the eigenbasis of H(B), so the sweep is spin-agnostic (it works on a tensor spin_tensor_basis too). For a fixed coherent Hamiltonian with field-dependent jumps, use the (basis, fields, H, make_jumps, c0, obs) form below; for a non-rate readout (a steady-state transfer profile, say), use sweep_field directly.

Examples

julia> b = restricted_basis(1, 1); c0 = state(b, polarized(1, :z)); Iz = spin_op(1, 1, 3);

julia> mk(Γ) = build_liouvillian(b, PauliDict(); jumps = decay(1, 1:1, Γ));

julia> r = rate_vs_field(b, [1.0, 2.0], mk, c0, Iz);

julia> (r.fields, round.(r.rates; digits = 4))        # ⟨Iz⟩ decays at 2Γ
([1.0, 2.0], [2.0, 4.0])
source
RestrictedSpinDynamics.rate_vs_field — Method
rate_vs_field(basis, fields, H, make_jumps, c0, obs; relative = true, kwargs...) -> (; fields, rates)

Convenience field sweep for a fixed coherent Hamiltonian H and field-dependent relaxation: at each B it builds build_liouvillian(basis, H; jumps = make_jumps(B), kwargs...) and reads the rate with initial_rate. This is the closed-form dispersion / NMRD case, where the field enters the relaxation model (ωI = γ B), as in the nitroxide NMRD gate. When the coherent H itself disperses with field, the eigenbasis redfield_jumps route at ZULF where H(B) must be rediagonalized, use the make_L form above instead. Extra kwargs pass through to build_liouvillian (e.g. check_sector = false).

Examples

julia> b = restricted_basis(1, 1); c0 = state(b, polarized(1, :z)); Iz = spin_op(1, 1, 3);

julia> r = rate_vs_field(b, [1.0, 2.0], PauliDict(), Γ -> decay(1, 1:1, Γ), c0, Iz);

julia> (r.fields, round.(r.rates; digits = 4))
([1.0, 2.0], [2.0, 4.0])

RestrictedSpinDynamics.steady_state — Method
steady_state(basis, L; trace = 1.0) -> Vector{ComplexF64}

The stationary state ρ_ss of the Lindbladian L (L c = 0), found directly: replace the identity row of L with the trace functional Tr(ρ) = 2^N c_id and solve the resulting nonsingular sparse system for Tr(ρ) = trace. A linear solve, not an eigendecomposition, so L's non-normality is irrelevant. Assumes a unique fixed point (ergodic dissipator); a non-ergodic L has a higher-dimensional kernel, so the solve returns only one member and a large residual ‖L ρ_ss‖ triggers a warning.

Examples

julia> basis = restricted_basis(1, 1);

julia> L = build_liouvillian(basis, PauliDict(); jumps = thermal_relaxation(1, 1:1, 1.0; p_eq = 0.4));

julia> round(2 * real(expect(basis, steady_state(basis, L), spin_op(1, 1, 3))); digits = 4)   # ⟨σz⟩_ss = p_eq
0.4
source
RestrictedSpinDynamics.sweep_field — Method
sweep_field(basis, fields, make_L, readout) -> (; fields, values)

Apply a readout to the generator across a parameter sweep. For each B in fields, make_L(B) returns the Liouvillian at that point and values[i] = readout(basis, make_L(B)). fields is whatever make_L consumes (typically a magnetic field). The readout chooses the physics: initial_rate for a relaxation-rate dispersion (wrapped as rate_vs_field), steady_state with expect for a transferred-polarization profile (a SABRE or level-anti-crossing field sweep), or any other L-derived quantity. make_L carries the whole field-dependence, so a J-coupled drift with a field-dependent Zeeman is built per point, and the sweep is spin-agnostic.

Examples

julia> b = restricted_basis(1, 1); Iz = spin_op(1, 1, 3);

julia> mkL(Γ) = build_liouvillian(b, PauliDict(); jumps = decay(1, 1:1, Γ));

julia> s = sweep_field(b, [1.0, 2.0], mkL, (bb, L) -> real(expect(bb, steady_state(bb, L), Iz)));

julia> (s.fields, round.(s.values; digits = 4))        # relaxes to the -z ground at every rate
([1.0, 2.0], [-0.5, -0.5])

GPU Backend

propagate_gpu is the CUDA path, mirroring propagate on the assembled sparse matrix. CUDA is loaded lazily, so the dependency is called only when this backend is called.

RestrictedSpinDynamics.propagate_gpu — Method
propagate_gpu(basis, L, c0, ts; observables, dt=nothing,
              save_trajectory=false, drift_check=false,
              drift_tol=1e-8, krylov_m=30, precision=:double,
              device=nothing)

GPU version of propagate; same interface and semantics, with the expv sparse matvec on the GPU. precision ∈ (:double, :single) (:single is faster on consumer GPUs but, since L is non-normal, should be validated per-system against :double); device optionally selects the CUDA device index. Requires CUDA.jl + a functional GPU.

Batched Ensembles

propagate_ensemble advances an Ensemble of $M$ independent isochromats (built by ensemble) as one batch. The exact per-block propagator $\exp(\Delta t\, \mathcal{L}_m)$ is precomputed and applied to all blocks at once (a batched matvec on the GPU), machine-precision exact and, for a large inhomogeneous ensemble, far faster than a per-isochromat loop (see Benchmarks). It is valid for constant generators and independent blocks: a generator that breaks the shared-basis equivalence is rejected by build_liouvillian, and population transfer between isochromats is the exchange regime instead.

RestrictedSpinDynamics.Ensemble — Type
Ensemble

M independent generators sharing one basis, propagated together as a batch. Built by ensemble, consumed by propagate / propagate_ensemble. Each generator is a dense d x d matrix (d = the shared basis dimension); weights[m] is the ensemble weight of block m, summed at readout.

source
RestrictedSpinDynamics.ensemble — Method
ensemble(L0::AbstractMatrix; offset=(D, deltas), weights=nothing) -> Ensemble
ensemble(Ls::AbstractVector{<:AbstractMatrix}; weights=nothing) -> Ensemble

An ensemble of M independent generators sharing one basis, built in one of two ways:

  • Offset case: L_m = L0 + deltas[m] * D - a base generator L0 plus a per-block scalar offset deltas[m] along a unit direction D. Any per-block detuning or disorder parameter fits; NMR isochromats in an inhomogeneous field are the canonical case (D = -i[Sz_tot, .], deltas[m] the Larmor offset).
  • Arbitrary blocks: pass the M dense generators Ls directly.

weights are the ensemble weights w_m (default uniform 1/M), summed at readout. Densify a sparse build_liouvillian result (Matrix(...)) on the reduced basis before handing it here.

source
RestrictedSpinDynamics.propagate_ensemble — Method
propagate(basis, ens::Ensemble, c0, ts; observables, backend=:cpu, precision=:double)
propagate_ensemble(basis, ens::Ensemble, c0, ts; kwargs...)
  -> (ts, traces, per_block_traces, drift)

Propagate an Ensemble of M independent generators over a uniform ts grid, sharing basis. c0 is the shared initial coefficient vector (replicated to all blocks), a length-M vector of per-block vectors, or a d x M matrix. Each block steps by its exact propagator exp(dt * L_m), so the run is machine-precision; backend=:gpu batches the steps into one gemm_strided_batched!, the path for large M. precision is :double (default) or :single. Returns (; ts, traces, per_block_traces, drift): traces the weighted ensemble average, per_block_traces the M x length(ts) per-block values (e.g. an NMR isochromat lineshape decomposition).

Valid only for time-independent, independent blocks with fixed weights. A scheduled generator needs propagate_sequence per segment; transfer between blocks (a gradient, chemical exchange) is the exchange compartment regime. check_sector_closure catches terms that break the spin equivalence a reduced basis assumes, before they can be silently averaged.

FID Spectrum

After an acquisition, spectrum takes the time-domain free-induction decay (an observable trace) to its frequency-domain spectrum (apodization + optional zero-fill), and peaks picks the lines out of it.

RestrictedSpinDynamics.peaks — Method
peaks(freqs, spectrum; height = 0.1, n = nothing) -> Vector{Tuple{Float64, Float64}}

Local maxima of abs.(spectrum) as (frequency, amplitude) pairs, sorted by descending amplitude. A bin is a peak if it exceeds both neighbors and the relative threshold height · maximum(abs, spectrum). Keeps only the top n if given. For picking lines out of a spectrum.

Examples

julia> dt = 0.01; ts = 0:dt:(2 - dt);

julia> fid = exp.(2im*π*20 .* ts) .+ 0.5 .* exp.(-2im*π*30 .* ts);

julia> s = spectrum(fid, dt); pk = peaks(s.freqs, s.spectrum; n = 2);

julia> Tuple(round.(first.(pk); digits = 1))   # +20 Hz strongest, then -30 Hz
(20.0, -30.0)
Experimental

FID post-processing is experimental in v1: deterministic, but not yet under a unit-test gate; the API may change.

source
RestrictedSpinDynamics.spectrum — Method
spectrum(fid, dt; lb = 0.0, zerofill = 0, window = nothing) -> @NamedTuple{freqs, spectrum}

Discrete NMR spectrum of a complex (or real) free-induction decay fid sampled at spacing dt (seconds). Applies Lorentzian apodization exp(-π · lb · t) (lb = line broadening in Hz; lb = 0 is none) and, when window is given, a tapered window (:tukey, or any length-fid vector), optionally zero-fills by appending zerofill samples, then returns the fftshifted spectrum and its matching freqs axis (Hz). spectrum is complex: abs.(spectrum) is the magnitude, real.(spectrum) the absorption mode after phasing.

Examples

julia> dt = 0.01; ts = 0:dt:(2 - dt); fid = exp.(2im*π*20 .* ts) .* exp.(-ts ./ 0.5);

julia> s = spectrum(fid, dt; lb = 1.0);

julia> length(s.freqs) == length(s.spectrum) == length(fid)
true

julia> round(s.freqs[argmax(abs.(s.spectrum))]; digits = 1)   # peak at +20 Hz
20.0
Experimental

FID post-processing is experimental in v1: deterministic, but not yet under a unit-test gate; the API may change.
