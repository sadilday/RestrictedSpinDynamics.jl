Basis & Symmetry

restricted_basis enumerates the Pauli, ladder, or spherical-tensor strings of grade <= kmax and builds an index from string label to coefficient-vector position. On top of the grade cap of Grade Truncation and Polynomial State Space Scaling, a symmetry the initial state and observable share lets you keep only the invariant sector they occupy, an exact reduction. The concepts and when each applies are in Symmetry Capabilities.

  • Restricted Basis
  • Higher-Spin (Radix) Basis
  • Symmetry Reductions

Restricted Basis

lookup returns 0 for any string of grade > kmax; that zero is the SSR projection. The pluggable index backends (DictIndex, SortedIndex, RadixIndex) trade build time against memory (RadixIndex is named for its mixed-radix arithmetic ranking, not the higher-spin radix below). Past the 64-spin tableau cap, restricted_basis switches automatically to the sparse grade-scaled labels (see Pauli, Ladder & Tensor Algebra), keyed through RadixIndex; the API is unchanged. dla_dimension computes the grade at which the dynamical Lie algebra closes, i.e. the smallest kmax for which the truncation is exact; a higher-spin (tensor) method dla_dimension(N, generators, radix) and the rank-resolved dla_report extend this to spin > 1/2 (see Higher-Spin). ClusterSpec restricts to named correlation blocks of spins (with a spectator set carrying identity).

RestrictedSpinDynamics.AbstractIndex — Type
AbstractIndex

Pluggable backend mapping a label to its 1-based position in a RestrictedBasis, or 0 if absent (grade > kmax or wrong sector); that 0 is the SSR projection. Sits behind lookup (the hot read path in build_liouvillian): DictIndex (O(1), more memory), SortedIndex (O(log dim), compact), or RadixIndex (pure arithmetic, no per-row map, carries the full grade basis past N = 64).

RestrictedSpinDynamics.ClusterSpec — Type
ClusterSpec(blocks; max_block_span = 1, spectator = Int[])

Correlation-cluster restriction for restricted_basis. blocks is a list of named spin blocks (name, sites) or (name, sites, kmax) (per-block correlation cap; uncapped if the kmax is omitted); max_block_span caps how many distinct blocks a single Pauli string may span (1 = product across blocks); spectator sites carry identity only. The blocks and spectator sites must partition 1:N.

Examples

julia> length(restricted_basis(5, 4; clusters = cs)) < length(restricted_basis(5, 4))   # smaller
true

RestrictedSpinDynamics.DictIndex — Type

Hash-map index: O(1) lookup, ~70 B/row (default). Parametric in the label type L so it serves every representation.

source
RestrictedSpinDynamics.RadixIndex — Type
RadixIndex <: AbstractIndex

Arithmetic index for the full grade-≤kmax basis: ranks a label by grade class, the lexicographic rank of its occupied-site subset, and a mixed-radix digit string of its per-site letters, rank(p) = offset[g] + lexrank(sites)·Aᵍ + Σⱼ(lⱼ−1)·Aʲ⁻¹ (A = letters per site, 3 for Pauli). O(grade) lookup, O(kmax) storage, no per-row map (the memory win over DictIndex), and pure integer arithmetic - so it carries the basis past N = 64. Full grade basis only: no parity/weight sector, symmetry, or clusters, and uniform radix (those break the ranking bijection and keep DictIndex/SortedIndex).

The name refers to the mixed-radix integer arithmetic of the ranking, not the higher-spin radix (per-site dimension): RadixIndex is the :auto default for any full-grade basis, Pauli or uniform higher-spin alike.

source
RestrictedSpinDynamics.RestrictedBasis — Type
RestrictedBasis{I<:AbstractIndex, L, S}

The grade-truncated operator basis: all strings of type L (PauliLabel or LadderLabel) with grade ≤ kmax on N spins in canonical grade-major order, plus a pluggable AbstractIndex. sector records the exact sub-block (nothing = full, :even/:odd = Pauli coherence-order parity, w::Int = ladder weight); sym is any site-permutation adaptation; radix is the per-site Hilbert dimension (empty ⇒ uniform spin-1/2). A coefficient vector c then represents ρ = Σ_α c_α P_α. Construct with restricted_basis.

source
RestrictedSpinDynamics.SortedIndex — Type

Sorted-permutation index: stores only sortperm(labels) (~8 B/row), O(log dim) lookup, best when the basis is large and memory-bound.

RestrictedSpinDynamics.basis_size — Method
basis_size(N, kmax; parity=nothing) -> Int
basis_size(b::RestrictedBasis) -> Int

Dimension of the retained basis. The (N, kmax) form is the closed count for the spin-1/2 Pauli-string basis, Σ_{g=0}^{kmax} C(N,g) 3^g (= 4^N at kmax = N; ≈ (3N)^kmax/kmax! for kmax ≪ N), reporting cost before building: basis_size(N, kmax) == length(restricted_basis(N, kmax)). With parity=:even/:odd the per-grade block 3^g becomes (3^g ± (-1)^g)/2 (even/odd count of transverse X/Y sites).

No closed form covers the other basis variants: higher spin (the per-grade block is (d^2-1)^g), or symmetry-adapted, weight-sector, and cluster bases. For those, pass the built basis b and the exact size is read from its length.

Examples

julia> basis_size(4, 2)                 # matches length(restricted_basis(4, 2))
67

julia> basis_size(4, 4)                 # kmax = N is the full 4^N space
256

julia> basis_size(4, 2; parity=:even)   # even-parity sector, ~2x smaller
35

julia> basis_size(restricted_basis(2, 2; radix=3))   # spin-1 (d=3): read from length, not 3^g
81

RestrictedSpinDynamics.dla_dimension — Method
dla_dimension(N, generators) -> Int
dla_dimension(N, generators::Vector{TensorDict}, radix) -> Int

Dimension of the dynamical Lie algebra generated by generators under commutation, the number of distinct Pauli strings reachable by nested commutators. The exact truncation floor: SSR at grade k is exact iff every DLA string has grade ≤ k (compare basis_size(N, k)). Theory: Wiersema et al., npj QI 10:110 (2024).

For higher spin, pass TensorDict generators over sites of dimension radix: a tensor commutator is a sum of spherical tensors, so the DLA is closed by a span (Gaussian elimination) whose complex dimension equals the real DLA dimension (reproducing the Pauli count at d = 2). See dla_report and Higher-Spin.

Examples

julia> dla_dimension(1, [(UInt64(1), UInt64(0)), (UInt64(0), UInt64(1))])   # {X, Z} closes to {X, Y, Z}
3

RestrictedSpinDynamics.hilbert_dim — Method
hilbert_dim(basis) -> Float64
hilbert_dim(N::Integer) -> Float64

Hilbert-space dimension ∏_k (2 S_k + 1) setting the trace/orthogonality scaling, Tr(P_β P_α) = hilbert_dim · δ (so Tr(ρ) = hilbert_dim · c_identity). Uniform spin-1/2 reduces to 2^N; the higher-spin basis reads per-site S from radix. The integer form gives a bare N-site spin-1/2 block (sub-block traces). Float64 because every caller uses it in floating-point trace arithmetic.

RestrictedSpinDynamics.lookup — Method
lookup(b::RestrictedBasis, p) -> Int

1-based index of label p, or 0 if it lies outside the kept basis (grade > kmax or wrong sector). That 0 is the SSR projection. Generic in the label type, so a Pauli probe hits a Pauli basis and a ladder probe a ladder basis.

julia> lookup(b, PAULI_ID)                     # identity is row 1 (grade 0)

julia> lookup(b, (UInt64(0b111), UInt64(0)))   # grade-3 XXX is beyond kmax = 2
0

RestrictedSpinDynamics.memory_estimate — Method
memory_estimate(N, kmax; parity = nothing) -> (; dim, state_bytes, dense_bytes, hilbert_dim, full_dim, full_dense_bytes)

A-priori size/memory report for a grade-kmax restricted spin-1/2 simulation on N spins, from closed-form counts WITHOUT building the basis or Liouvillian. dim = basis_size(N, kmax; parity) is the coefficient-vector length (the Liouvillian side length). state_bytes = 16 dim is the ComplexF64 coefficient vector, the footprint matrix-free propagate scales with; dense_bytes = 16 dim² is the dense-superoperator upper bound (the sparse Liouvillian's actual nnz is system-dependent and far smaller, measurable with Base.summarysize on a built build_liouvillian). hilbert_dim = 2^N, and full_dim = 4^N with full_dense_bytes = 16·16^N are the untruncated full-Liouville figures the grade truncation avoids.

Examples

julia> r = memory_estimate(4, 2);

julia> (r.dim, r.state_bytes)              # 67 coefficients, 16 bytes each
(67, 1072)

julia> memory_estimate(20, 2).dim == basis_size(20, 2)   # grade-2 on 20 spins, no 4^20 blowup
true

RestrictedSpinDynamics.restricted_basis — Method
restricted_basis(N, kmax; parity=nothing, weight=nothing, symmetry=nothing, radix=nothing, clusters=nothing, index=:auto) -> RestrictedBasis

All Pauli strings on N spins with grade ≤ kmax (kmax = N gives the full 4^N basis, exact dynamics). The verb-layer entry point; the keyword sectors are exact reductions and compose where noted:

  • parity (:even/:odd): coherence-order-parity sector, ~2x, valid when the dynamics conserves total Sz (`checksectorclosureenforces it).:even` holds an Sz start + ⟨I_z⟩ observables; :odd is the single-quantum (FID) sector.
  • weight = w: a ladder basis (ladder.jl) of definite coherence order w = #σ⁺ − #σ⁻, an exact S_z-block and a further ~3-8x. Mutually exclusive with parity (ladder vs Pauli representation).
  • symmetry: a site-permutation adaptation (symmetry/adaptation.jl), a SpinClasses or PointGroup; rows become orbit averages. Exact when H and the jumps are group-invariant, and composes with parity/weight. One SpinClasses class gives dimension C(kmax+3,3), independent of N.
  • radix: a higher-spin basis ([d_1,...,d_N] or a scalar d, d_s = 2 S_s + 1); strings become SpinTensorLabel tensors. Composes with symmetry, clusters, and weight (not Pauli parity). The unified entry point for spin_tensor_basis; pair with the radix term methods.
  • clusters: a ClusterSpec correlation-cluster restriction.

Examples

julia> length(restricted_basis(4, 2))      # populations + 1- and 2-spin correlations
67

julia> length(restricted_basis(4, 4))      # kmax = N is the full 4^N space
256

julia> length(restricted_basis(4, 2; parity=:even))   # exact even-parity sector (~2x smaller)
35

julia> length(restricted_basis(2, 2; radix = 3))      # two spin-1 sites: full 9^2 tensor space
81
source
RestrictedSpinDynamics.spin_tensor_basis — Method
spin_tensor_basis(N, kmax, radix; index = :auto) -> RestrictedBasis
spin_tensor_basis(N, kmax, d::Integer; index = :auto) -> RestrictedBasis

Grade-truncated spherical-tensor basis for N sites: all SpinTensorLabel strings of grade <= kmax, each non-identity site s carrying one of its d_s^2 - 1 tensor letters. radix = [d_1, ..., d_N] is the per-site Hilbert dimension (d_s = 2S_s + 1; a scalar d for uniform spin, mixed radix supported). The higher-spin twin of restricted_basis; the basis records radix so hilbert_dim returns prod(radix). A weight = w keyword restricts to the definite coherence-order sector (Σ q = w), an exact Sz-block that composes with symmetry. Pair with [`tensorop](@ref) terms and the [build_liouvillian`](@ref) tensor dispatch.

Experimental

This is the lower-level constructor; prefer restricted_basis(N, kmax; radix = ...) as the unified entry point. The surface (basis, state, operator constructors) is still being unified into the spin-1/2 API, so it may change.

Higher-Spin (Radix) Basis

For spin > 1/2 the basis is parameterized by a radix, the per-site dimension vector $[d_1, \dots, d_N]$ ($d_s = 2S_s + 1$). Set it directly with restricted_basis(N, kmax; radix = d) (a scalar for a uniform spin, a vector for mixed radix), or let a SpinSystem derive it from the isotopes with restricted_basis(ss, kmax); spin_tensor_basis is the lower-level form both route to. The strings themselves are the spherical-tensor tableau of Pauli, Ladder & Tensor Algebra. hilbert_dim ($\prod_s d_s$) is the trace dimension, and RadixIndex is the index backend matched to the packed tableau.

The exactness floor carries over, with its computation extended by rank: the tensor method dla_dimension(N, generators, radix) and the rank-resolved dla_report give the grade (and multipole rank) at which the dynamical Lie algebra closes. Symmetry composes with one caveat: a site-permutation orbit can relate only sites of equal dimension, so SpinClasses / PointGroup apply to magnetically equivalent equal-spin sites. The higher-spin composers, state constructors, and workflow are in the Higher-Spin guide.

RestrictedSpinDynamics.dla_report — Function
dla_report(N, generators, radix; maxdim=20000, tol=1e-9) -> NamedTuple
dla_report(N, generators::Vector{PauliLabel}) -> NamedTuple

Rank-resolved report on the dynamical Lie algebra generated by generators (see dla_dimension). The higher-spin form takes the terms as TensorDicts over radix; a spin-1/2 PauliLabel twin is provided so the report reads uniformly. Fields:

  • dim: the DLA dimension.
  • grade_floor: the smallest kmax for which grade truncation is exact (max grade over the algebra).
  • rank_ceiling: the highest per-site multipole rank reached; gen_rank: the max rank in the generators; rank_bounded = (rank_ceiling == gen_rank) is false when commutators climbed the rank ladder (only possible for spin >= 3/2, where [rank-2, rank-2] opens rank-3).
  • grade_dims[m+1] = dim(DLA ∩ {grade <= m}) for m = 0:N; rank_dims[r+1] = dim(DLA ∩ {rank <= r}) for r = 0:max(2S): the grade and rank filtrations (shell profiles).
  • capped: whether the maxdim safety cap was hit before closure.

See Higher-Spin.

Symmetry Reductions

A symmetry the initial state and observable share blocks the generator into invariant sectors, so restricting to the occupied sector is exact and composes with the grade cap. The concepts and when each applies are in Symmetry Capabilities; this is the API reference.

Two sectors come for free from the string structure, set by a keyword to restricted_basis: the Pauli parity sector and the definite total-$S_z$ weight sector. check_sector_closure tests whether a generator preserves a sector, and build_liouvillian raises a labelled error rather than projecting silently when it does not.

Site-permutation symmetry keeps one representative per orbit. The 1D-irrep adaptation (SpinClasses for equivalent spins, PointGroup for an explicit group) is used directly by restricted_basis through the symmetry keyword; it is complete for every abelian group.

RestrictedSpinDynamics.AbstractSpinSymmetry — Type
AbstractSpinSymmetry

A site-permutation symmetry used to adapt a RestrictedBasis (pass as symmetry= to restricted_basis). When H and every jump are G-invariant, 𝓛 block-diagonalizes over the irreps of G; each 1D-irrep row is a normalized orbit average Q_λ = (1/|O_λ|) Σ_{P∈O_λ} χ(h_P)* P, still addressed by one label (the canonical representative) plus a phase, so canon + lookup_sym is the whole change. The projection/re-expansion |O| factors cancel in 𝓛, so the orbit sizes live on the state side (expect divides by them, the state builders multiply). Concrete types: SpinClasses and PointGroup; the 1D adaptation is complete for abelian groups, while multi-dimensional irreps need in-orbit superpositions and live in symmetry/blocks.jl. Its nspins is N.

source
RestrictedSpinDynamics.PointGroup — Type
PointGroup(N, gens; character = 1) -> PointGroup

A finite site-permutation group on N spins, closed from the generator list gens (each a permutation of 1:N as a Vector{Int}). canon minimizes the label over the element list, so this is for genuinely small groups (|G| ≲ 48).

character selects the 1D irrep to project onto: an index into one_dim_characters (1 is always trivial) or an explicit Vector{ComplexF64} over the elements, validated as a homomorphism. Every abelian point group has only 1D irreps, so for those this is a complete decomposition of the Liouvillian.

Examples

julia> pg = PointGroup(3, [[2, 3, 1]]);   # C₃ cyclic on 3 sites

julia> length(pg.elements)
3

julia> length(restricted_basis(3, 2; symmetry = pg))   # vs 37 unsymmetrized
13
source
RestrictedSpinDynamics.SpinClasses — Type
SpinClasses(N, classes) -> SpinClasses

Permutation symmetry of N spins under independent permutation of each class of magnetically equivalent spins (S_{n₁} × … × S_{n_M}, never enumerated). classes is a vector of site groups; any unlisted site is its own singleton. canon sorts site values within each class by popcount, so this works at N = 30 or 64, and a single class has symmetric-sector dimension C(kmax+3,3) regardless of N. Only the trivial character is supported (the S_n sign character annihilates every orbit here by pigeonhole on the four-letter {I,X,Y,Z} alphabet).

Examples

julia> length(restricted_basis(4, 2; symmetry = SpinClasses(4, [[1, 2, 3, 4]])))   # C(5,3)
10

julia> length(restricted_basis(5, 2; symmetry = SpinClasses(5, [[1, 2, 3, 4, 5]])))   # same
10

RestrictedSpinDynamics.is_invariant — Method
is_invariant(sym, jumps::AbstractVector) -> Bool

Whether a Lindblad dissipator (a list of (jump_operator, rate) pairs) is invariant under sym. A jump SET can be symmetric even when its members are not ({σ⁺_s : s ∈ class} maps onto itself under a site permutation), so this holds iff every generator permutes the (operator, rate) multiset onto itself (rates matched with ≈). Strictly weaker than per-jump invariance, which a symmetric build_liouvillian still requires today, so this predicate is for analysis, not yet a licence to pass a per-site jump set.

RestrictedSpinDynamics.lookup_sym — Method
lookup_sym(basis, p) -> (index, phase)

Index of the symmetry-adapted row that Pauli string p belongs to, with the character phase χ(h_p) relating p to the stored representative. index == 0 means p is outside the basis (grade > kmax, wrong sector, or an orbit annihilated by the character). The single read choke point for a symmetry-adapted basis; on an unsymmetrized basis it reduces to plain lookup.

RestrictedSpinDynamics.one_dim_characters — Method
one_dim_characters(pg) -> Vector{Vector{ComplexF64}}

Every one-dimensional irrep of the group, as a character vector over pg.elements; the first entry is always the trivial character. Found by assigning each generator a root of unity of its own order, extending along the stored generator words, and keeping the assignments that satisfy χ(g)χ(h) = χ(gh) on the multiplication table. For an abelian group this is the complete irrep list.

RestrictedSpinDynamics.symmetry_project — Method
symmetry_project(basis, coeff_of) -> Vector{ComplexF64}

Build a coefficient vector from coeff_of, a function giving the coefficient of an arbitrary Pauli string. On an unsymmetrized basis this evaluates coeff_of on each label; on a symmetry-adapted basis it projects onto the basis's character sector, c_λ = Σ_{r∈O_λ} χ(h_r) v_r. PointGroup sums that over the group, so a non-invariant state still projects correctly; SpinClasses cannot enumerate the group, so it requires a state constant on each orbit (the sum collapses to c_λ = |O_λ| v_{P_λ}) and verifies that per row.

RestrictedSpinDynamics.character_table — Method
character_table(pg) -> CharacterTable

Irreducible characters from the multiplication table alone (Burnside-Dixon; Dixon, Numer. Math. 10, 446 (1967)), since cycle type on the sites is not a faithful class key (in Oh, inversion and the edge C₂'s share cycle type). RestrictedSpinDynamics.irrep_multiplicities — Method
irrep_multiplicities(pg, labels; table) -> NamedTuple

Multiplicity m_a of each irrep in the space spanned by labels (pass basis.labels, or a RestrictedBasis directly). Returns (labels, dims, mults, dim, largest, stored, table) where largest = max m_a is the biggest block a full symmetry adaptation would produce, and stored = Σ m_a is the total dimension that would have to be held. RestrictedSpinDynamics.propagate_blocks — Method
propagate_blocks(sb, L, c0, ts; observables, dt) -> NamedTuple

Propagate through every symmetry block independently and sum the observable contributions. L is the Liouvillian assembled on sb.basis and c0 the ordinary full coefficient vector; the projection onto blocks and the recombination are handled here.

Each block is small, so its propagator is formed by a dense matrix exponential (scaling and squaring, safe on a non-normal generator, unlike an eigendecomposition) and reused every step. Returns (ts, traces) matching propagate.

RestrictedSpinDynamics.symmetry_blocks — Method
symmetry_blocks(N, kmax, pg; table, irreps) -> SymmetryBlocks

Full block decomposition of the grade-kmax basis on N spins under pg, including multi-dimensional irreps. irreps selects which to build (default all). The construction uses only the character table plus the eigenspaces of one Hermitian group-algebra element, so no irrep matrices are needed and no per-orbit basis has to be reconciled. The change of basis depends only on the group and basis, never on H, so a parameter scan reuses it.

The block dimensions reproduce the multiplicities irrep_multiplicities predicts, which is checked during construction: a rank mismatch throws, guarding against a silently truncated block.

Examples

julia> pg = PointGroup(3, [[2, 3, 1], [1, 3, 2]]);   # C₃ᵥ ≅ S₃

julia> sb = symmetry_blocks(3, 2, pg);   # blocks: trivial, sign, 2×(2D copies)

julia> length(sb)
4

julia> sum(blk.dim for blk in sb.blocks)   # copies of every block tile the full basis
37
