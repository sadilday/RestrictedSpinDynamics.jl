Average Hamiltonian (AHT)

Experimental

RestrictedSpinDynamics.AHT is a small, lightly experimental design layer and is prone to change: its API is not covered by the v1 stability guarantee. See Public API & Stability.

Access

These names are not brought in by using RestrictedSpinDynamics. Reach them with using RestrictedSpinDynamics.AHT (then spin_operators, hard_pulse, ... are in scope), or call them qualified as RestrictedSpinDynamics.AHT.average_hamiltonian.

RestrictedSpinDynamics.AHT designs multiple-pulse sequences (WAHUHA, MREV) by their average Hamiltonian: transform the drift into the toggling_frame of a pulse train, expand the effective Hamiltonian in the Magnus series $\bar H = \bar H^{(0)} + \bar H^{(1)} + \dots$ (magnus, or sum it with effective_hamiltonian), and optimize_windows the inter-pulse delays to null a target interaction to a chosen order.

Because the toggling-frame Hamiltonians are piecewise-constant over the windows, every Magnus order is exact (a closed form, no quadrature), so the only cost control is the requested order (4 is ample for design work). The all-orders reference effective_hamiltonian(Hs, tau; order = :exact) is $(i/T)\log U$ from the one-cycle propagator, which the truncated Magnus sum converges to. This is coherent control on dense Hilbert operators (small systems); the grade-truncated engine then validates the designed sequence. Full signatures below.

Example

A symmetric spin-echo (a single pi pulse, equal windows) nulls the Zeeman interaction to every order, since the two toggling-frame windows are +H and -H and commute:

julia> using RestrictedSpinDynamics.AHT, LinearAlgebra

julia> Ix, Iy, Iz = spin_operators(1);

julia> H = 2pi * 5.0 * Iz[1];                                   # a 5 Hz offset (Zeeman)

julia> Hs = toggling_frame(H, [hard_pulse(Ix, Iy, 1:1, 0.0; β = pi)]);   # pi-pulse echo

julia> [round(norm(t); digits = 10) for t in magnus(Hs, [1.0, 1.0]; order = 3)]
4-element Vector{Float64}:
 0.0
 0.0
 0.0
 0.0

For non-commuting windows the higher orders are nonzero, and summing them reconstructs the exact effective Hamiltonian:

julia> using RestrictedSpinDynamics.AHT, LinearAlgebra

julia> Ix, Iy, Iz = spin_operators(1);

julia> A = 0.8 * Iz[1]; B = 0.6 * Ix[1];                        # two non-commuting windows

julia> Hs = [A, B]; τ = [0.5, 0.4];

julia> length(magnus(Hs, τ; order = 4))                         # H̄⁽⁰⁾ … H̄⁽⁴⁾
5

julia> norm(magnus(Hs, τ; order = 0)[1] - average_hamiltonian(Hs, τ)) < 1e-12
true

julia> norm(sum(magnus(Hs, τ; order = 5)) - effective_hamiltonian(Hs, τ; order = :exact)) < 1e-6
true

Bridge to the Engine

A design is only useful once the sparse engine runs it. toggling_frame and to_sequence take the same engine pulse elements, so one pulse-train description drives both the dense design math and the propagate_sequence simulation, with no hand re-expression. The windows τ (n + 1 of them for n pulses) cross the boundary unchanged:

julia> using RestrictedSpinDynamics, RestrictedSpinDynamics.AHT

julia> N = 2; HD = dipolar(N, 1, 2, 1.0);                      # named-term drift, built once

julia> els = (pulse(1:N; θ = π/2, φ = 0.0, label = "x"),      # the pulse train, described once
              pulse(1:N; θ = π/2, φ = π/2, label = "y"));

julia> Hs = toggling_frame(N, HD, els);                       # design: ideal pulses, dense

julia> τ = optimize_windows(Hs, fill(1.0, length(els) + 1));  # null the drift to 0th order

julia> seq = to_sequence(N, HD, els, τ; ω1 = 2pi * 5e4);      # bridge: same els + τ -> Segments

julia> [s.label for s in seq]                                 # delay, pulse, delay, pulse, delay
5-element Vector{String}:
 "τ"
 "x"
 "τ"
 "y"
 "τ"

seq is an ordinary Vector{Segment}, so propagate_sequence(basis, seq, c0; jumps, observables) simulates the designed cycle in the restricted basis. The design assumes ideal delta pulses; the engine realizes finite pulses of duration θ/ω1, so pass a large ω1 to match the design (the two agree as ω1 -> Inf).

RestrictedSpinDynamics.AHT — Module
RestrictedSpinDynamics.AHT

Average-Hamiltonian design of coherent multiple-pulse sequences (WAHUHA, MREV, ...): build dense spin operators and ideal hard pulses, transform H into the toggling frame of a pulse train, and expand the effective Hamiltonian in the Magnus series H̄ = H̄⁽⁰⁾ + H̄⁽¹⁾ + ... to arbitrary order (magnus, effective_hamiltonian; average_hamiltonian is the H̄⁽⁰⁾ = Σ τₖ H̃ₖ / T term). Because the toggling-frame Hamiltonians are piecewise-constant over the windows, every order is exact (closed form, no quadrature). optimize_windows then nulls a target interaction to a chosen order. Dense Hilbert-space operators (small systems); the grade-truncated Liouville engine validates the designed sequence.

This submodule is lightly experimental and definitely prone to change: its API is not covered by the v1 stability guarantee.

RestrictedSpinDynamics.AHT.effective_hamiltonian — Method
effective_hamiltonian(Hs, τ; order = :exact) -> H̄

The effective (average) Hamiltonian H̄ with U = exp(-i H̄ T). With order::Int, the Magnus sum Σ_{m≤order} H̄⁽ᵐ⁾ (see magnus); with order = :exact, the exact all-orders value (i/T) log U from the matrix log of the ordered product ∏ₖ exp(-i τₖ H̃ₖ): the reference the truncated expansion converges to.

Ideal (delta) pulse of flip angle β about the phase axis φ (in the xy-plane) applied to spins.

RestrictedSpinDynamics.AHT.magnus — Method
magnus(Hs, τ; order::Int) -> [H̄⁽⁰⁾, H̄⁽¹⁾, …, H̄⁽ᵒʳᵈᵉʳ⁾]

Order-resolved Magnus expansion of the effective Hamiltonian H̄ defined by the one-cycle propagator U = exp(-i H̄ T) = exp(-i H̃ₙ τₙ) ⋯ exp(-i H̃₁ τ₁), for piecewise-constant toggling-frame Hamiltonians Hs = [H̃₁, …, H̃ₙ] over windows τ (period T = Σ τ). Returns order + 1 terms, H̄⁽ᵐ⁾ carrying m nested commutators (m + 1 Hamiltonian factors); H̄⁽⁰⁾ == average_hamiltonian(Hs, τ) and H̄⁽¹⁾ == (-i/2T) Σ_{k>l} τₖ τₗ [H̃ₖ, H̃ₗ].

Because the H̃ₖ are constant over each window, the terms are exact (closed form, no quadrature): they are the λ^{m+1} coefficients of (i/T) log ∏ₖ exp(-i λ τₖ H̃ₖ), extracted with truncated-series matrix arithmetic. Sum the returned terms (or use effective_hamiltonian) to reconstruct H̄.

source
RestrictedSpinDynamics.AHT.optimize_windows — Method
optimize_windows(Hs, τ0; order=0, T=sum(τ0), steps=20000, lr=0.25) -> τ

Optimize the inter-pulse windows to minimize ‖effective_hamiltonian(Hs, τ; order)‖ (null the interaction to the given Magnus order), on the simplex {τ ≥ 0, Στ = T}. For order = 0 (default) the cost is quadratic in τ, so projected gradient (with a decaying step) converges to the window pattern that averages the interaction away; higher order makes the cost non-convex (local minima possible), so seed τ0 near a good guess.

Higher-spin form: spin_operators(N, radix) gives prod(radix)×prod(radix) dense per-site operators, so the whole AHT path (toggling frame, Magnus, window optimization) runs for spin ≥ 1 on dense operators.

RestrictedSpinDynamics.AHT.spin_operators — Method
spin_operators(N) -> (Ix, Iy, Iz)

Dense spin-½ operators for N spins, lifted from the engine's spin_op via dense_operator (single source of truth). Each of Ix,Iy,Iz is a length-N vector of 2^N×2^N matrices, Ix[s] on spin s. Build interaction Hamiltonians the same way, e.g. dense_operator(dipolar(N, i, j, d), N).

RestrictedSpinDynamics.AHT.to_sequence — Method
to_sequence(N, Hdrift, elements, τ; ω1, radix = nothing) -> Vector{Segment}

Lower an AHT design to engine Segments for propagate_sequence. Interleaves the n + 1 inter-pulse windows τ with the n pulse(...) elements in time order (delay(τ[1]), element₁, delay(τ[2]), …, elementₙ, delay(τ[n+1])) over the drift Hdrift, then calls sequence. ω1 is the finite drive strength the engine uses to turn each flip angle into a duration; AHT designs assume ideal delta pulses, so pass a large ω1 to approximate them (the two agree as ω1 -> Inf). radix forwards to the higher-spin sequence method, and the AHT analysis path runs for spin ≥ 1 through spin_operators(N, radix) and the tensor toggling_frame method.

source
RestrictedSpinDynamics.AHT.toggling_frame — Method
toggling_frame(H, pulses) -> [H̃₁, …, H̃_{n+1}]

The system Hamiltonian H viewed in the toggling frame of a train of n pulses: H̃ₖ = Uₖ† H Uₖ, where Uₖ is the product of the first k−1 pulses (so H̃₁ = H, before any pulse). Returns n+1 Hamiltonians, one per inter-pulse window.

source
RestrictedSpinDynamics.AHT.toggling_frame — Method
toggling_frame(N, Hdrift::TensorDict, elements, radix) -> [H̃₁, …]

Higher-spin toggling frame: the same ideal-pulse construction on the dense prod(radix) space for a tensor drift Hdrift (e.g. quadrupole(N, sites, radix; …)). Feed the result to magnus / average_hamiltonian as at spin-1/2.

source
RestrictedSpinDynamics.AHT.toggling_frame — Method
toggling_frame(N, Hdrift::PauliDict, elements) -> [H̃₁, …, H̃_{n+1}]

Toggling frame of a spin-1/2 drift Hdrift (a named-term PauliDict, e.g. dipolar(N, i, j, d)) under a train of engine pulse(...) elements. The pulses are treated as ideal (delta) rotations, so the same elements you hand to to_sequence drive the design here; feed the result to magnus / average_hamiltonian / optimize_windows.
